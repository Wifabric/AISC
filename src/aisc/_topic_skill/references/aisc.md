# AISC 接入与启动

## AISC 主题对话模式

在主题面板创建或启用主题后，新开的Claude/Codex会话由平台通过原生背景指令加载主题skill、手册和进度的有界快照，不自动提交用户消息。AI等待用户真实发言后再工作；仅打开或恢复会话不触发开场、文件检查、成果生成或手册修订。已载入的信息直接使用，缺失、截断或需更新的资料在处理用户任务时按需读取。用户直接在普通对话中提问、安排任务和反馈，不需要反复提交表单。平台根据精确会话标识同步对外文本到journal；Agent继续负责决策、实践与手册修订，不能用原始聊天代替整理后的手册。任务执行时原生CLI仍可能显示工具活动，这不等于平台自动提交开场消息。

每轮有新约束、方法或反馈时保存依据、快照并修订手册/状态。平台原话记录可能稍晚出现，不重复假造逐字记录。应用未运行或同步失败时不能声称平台已保存；原Agent日志保留，恢复后补同步。旧会话不被追溯采集。切换主题只影响新会话，已有会话继续使用原主题。

主题页“迭代”展示ITERATION_LOG.md，采用日期加修改摘要的连续日志。平台从revision及关联事件生成，Agent负责提供事实与修订字段；不直接改写生成文件。历史缺少的理由或验证明确显示未记录。现有主题保持原skill副本，新会话的协作约定会补充最新记录要求。

## 独立使用：无需安装全局技能

把整个 topic-workshop 文件夹放在 AISC 当前工作区能访问的位置。向当前 Claude/Codex 会话提供 SKILL.md 的实际路径，要求读取并使用；再给出主题、资料和主题输出目录。相对路径必须以实际工作区为基准。

启动模板（将占位内容和路径替换成实际信息）：

> 读取并使用 skills/topic-workshop/SKILL.md。主题是〈主题名称〉，目标是〈具体成果〉，当前条件是〈资源与限制〉。资料在 inputs/，主题工作目录是 topics/my-topic。请推进当前任务，并记录沟通、实践和反馈。

恢复：

> 使用 topic-workshop，继续 topics/my-topic。先核对状态与文件，再推进上次的下一步。

反馈：

> 使用 topic-workshop。我试过上次方案，卡在这里……请记录反馈，分析原因，修订方法并安排当前能做的验证。

技能维护：

> 检查这个主题的迭代记录，提出可以改善通用 skill 的建议。先给依据和对比验证，不改安装版本。

## 按需安装

若用户要求常驻发现，先确认当前 Agent 的实际技能目录、已有同名版本和作用域，再复制整个技能目录。AISC 当前源码将 container/_bundle/skills/ 复制至 Claude 和 Codex 的工厂技能目录，但工厂打包与已有用户配置同步是不同流程；修改源码目录并不代表运行中的会话已经安装。

在容器中可读的运行时上下文（若存在 /run/aisc/runtime-context.json）及 CLAUDE_CONFIG_DIR、CODEX_CONFIG_DIR 可用于发现配置位置。不要假定宿主 D: 路径在容器可用，不默认覆盖已安装版本，不修改凭据/全局配置来试探。

安装验证：新会话实际能读取 SKILL.md 和引用资源；执行一个低风险主题任务。自动触发是否成功需要另外测试；显式读取成功不能宣称自动触发已验证。

## 文件记录与 Python

技能主要依赖 Agent 文件读写能力。workshop.py 是可选的可靠记录工具，需 Python 3.9+，无第三方依赖。无法运行 Python 时按 recording.md 协议用文件工具实现，不伪称已执行脚本校验。无法写文件时明确未持久化。

根目录由实际工作区/用户选择确定；各主题文件内使用相对路径以便迁移。展示链接遵循宿主要求；不要把只在容器有效的绝对路径误当成用户可打开的宿主路径。

## AISC 产物登记

在确认 aisc 可用、且会话已有身份信息时，按平台 artifact 约定登记手册和用户要打开的产物。例如对已确认的工作区相对路径：

```sh
aisc artifact record --path topics/my-topic/TOPIC_GUIDE.md --kind deliverable --action created --media-type text/markdown --label "主题手册"
```

修改已有文件使用 modified。身份由实际 AISC_AGENT、AISC_TERMINAL_SESSION_ID、AISC_RUNTIME_ID 提供，不伪造其他会话身份；不把整份日志逐条登记为交付物。接口不可用则保留文件并报告未登记。

## 首版边界

独立技能没有后台捕获功能；AISC主题对话模式由平台注入上下文并同步关联日志，不是技能自行监听。平台不复制推理、工具输出或附件二进制到主题记录，不自动修改全局技能。手册质量与真实长期效果仍需实际主题实践提供证据。
