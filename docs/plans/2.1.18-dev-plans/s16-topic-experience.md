## Preview.13 定向验收

1. 新标签 → 个人能力与主题：首先看到两个用途明确的入口；进入回答偏好，只需选择模板、编辑名称/规则、勾选启用并保存。历史和技术设置在进阶区域。原有能力和版本仍可打开。
2. 创建主题 A：填写名称/目标、选 Claude 或 Codex，创建后进入该主题的新对话。可编辑开场问题；只有点击填入才进入 AI 输入框，仍需自己按回车发送。
3. 从标签栏 + 新开普通 Claude/Codex：顶部不显示主题 A，继续聊天不归入 A；已启用的回答偏好仍独立生效。创建主题 B 后，在 A/B/普通对话间切换，状态与记录不串。
4. 从主题对话顶部查看成果：主题页能找到目标、继续按钮、相关对话、总结和成果文件；诊断、原始记录、修订历史默认折叠；记录保存不等于总结已整理。
5. 如已有截图中的历史同步错误：普通对话不再被它占满；对应主题内只显示简短中文提示，技术文字在更多中。关闭后相同错误不立即再出现，新错误仍可提醒。停止记录后旧记录仍在，后续消息不再采集。
