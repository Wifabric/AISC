# Preview.13：个人能力与主题定向验收

> 证据性质：本文保留相应候选的测试步骤与当时结果，不重写旧的 FAIL/NOT RUN。用户已确认整版与 Preview.13 通过，隔离安装已另行完成；当前提交/发布边界见 [发布准备](release-readiness.md)。

前一轮清单已由你报告通过。本次只检查新调整的体验，不要求重测镜像、模块或 GitHub PAT。新候选为 `2.1.18-preview.13`，开发者已完成实现、本地自动测试、真实进程/GUI 与 PR 验证；下列是你的使用效果验收。

## 打开正确版本

1. 先保存正在编辑的内容，正常关闭原 Preview.12 客户端；出现退出确认时确认，等待窗口消失。不要同时打开两个共用验收数据的版本。
2. 在资源管理器打开 `D:\AISC\p18`，双击 `打开 Preview13.cmd`。也可以在 PowerShell 执行：

   ```powershell
   & 'D:\AISC\p18\start-candidate13.ps1'
   ```

3. 打开原来验收用的工作区，保持原有镜像设置。帮助 → 关于 AISC Workbench：应显示 **Workbench 2.1.18-preview.13**，CLI/Bundle **0.1.10**。
4. 这次沿用之前的验收数据 `D:\AISC\p18\qa-data` 和 WebView 目录；无需重新安装，也不需要使用开发者的 `s16-ui-workspace`。安装包另在 `D:\AISC\p18\AISC Workbench_2.1.18-preview.13_x64-setup.exe`，日常验收用上述便携入口即可。

## 1. 普通对话不再跟随主题

1. 在标签栏加号旁的小箭头中选择 **Claude** 或 **Codex**，新开普通对话。
2. 随便问一个普通问题，例如“用两句话解释什么是版本控制”。
3. 查看顶栏，再去“个人能力与主题”查看原来的“短视频制作”主题。

通过标准：普通对话不显示主题状态条，不自动出现在旧主题相关对话或新增记录中；不会因为最近看过某个主题就被绑定。已启用的回答偏好仍可作用于新对话，这是与主题独立的功能。

旧对话已经收到过的主题上下文无法撤回；本项以新建普通对话为准。

## 2. 新手从哪里开始

1. 标签栏小箭头 → **个人能力与主题**。
2. 首屏应有 **设置我的回答偏好**、**围绕一个主题持续做事** 两个入口，并各有用途说明。
3. 进入回答偏好，选一个模板 → **创建个人副本**，或点 **新建空白能力**。
4. 名称填写“Preview13 偏好测试”，规则写“先给结论，再给两个具体步骤”。自行选择是否启用，点击 **保存新版本**；不必打开进阶设置。
5. 在 **我的能力 · 已保存的回答偏好** 中找到它。

通过标准：名称、规则和启用选项足以完成首次保存；出现第 1 版和准确的启停状态。技能、修改原因、验证与历史保留在进阶区域，不阻挡入门。若启用，可在新普通对话问“怎么整理桌面文件”，查看回答是否遵循规则；提问中不要重复规则。

## 3. 主动创建主题及开场问题

1. 回到 **围绕一个主题持续做事** → **新建主题**。
2. 名称填“Preview13 主题 A”，目标填“做一个三十秒的介绍视频，先给出三个步骤”，选择已配置好的 Claude 或 Codex，点击 **创建并开始主题对话**。
3. 在打开的主题对话中检查主题名称和开场草稿；先修改草稿，观察它尚未自动提交。
4. 点击 **填入对话，由我发送**。确认文本只进入输入框，自己按回车后才发送。

通过标准：只有这次从主题入口新开的对话关联 A；草稿可编辑且不会自动发送。未配置提供者时显示登录引导，不能把尚未启动的会话当成已运行；准备好后再完成此项。

## 4. A、B、普通对话互不串联

1. 按上一项再创建“Preview13 主题 B”，目标填“列出一周 Python 入门计划”。
2. 再通过标签栏小箭头新开一个普通对话。
3. 依次切换 A、B、普通对话，各发一条容易辨认的内容。
4. 在主题状态条点击 **更多 → 查看成果与相关对话**，回到主题页，查看目标、相关对话、总结与手册、成果文件。

通过标准：A/B 顶部仅显示自己的主题；普通对话没有主题条。相关对话和保存的记录不混入另一个主题或普通对话。原始记录、诊断、历史默认收起。没有生成作品时成果显示空态，不虚报已完成；记录已保存也不等于总结已整理。可对 Claude 和 Codex 各做一次主题/普通对话切换。

## 5. 顶部提示简化与停止记录

1. 打开以前出现过同步错误的主题对话，再切到普通对话。
2. 如果出现同步异常，查看中文摘要和更多详情；关闭提示，再等一轮同步。
3. 对一个测试主题对话点击 **更多 → 停止记录本次对话**；记下已保存内容，再发送一条新的辨认文本。

通过标准：普通对话不被旧主题错误占据；主题内不再铺满重复英文。相同错误关闭后不立即反复出现，技术详情可按需查看。停止后旧记录保留，之后的消息不再新增到该主题采集记录。停止采集不会撤回模型已收到的上下文。没有自然出现错误时，错误提示关闭项记“未遇到”，无需破坏环境制造错误；该逻辑已由开发者回归覆盖。

## 6. 重启与旧数据

1. 正常关闭客户端，确认退出并等待窗口消失，再用同一入口打开 Preview.13。
2. 回到同一工作区，打开个人能力与主题。
3. 查看原能力的版本历史、原主题手册/成果，以及新建的测试偏好和 A/B 主题。
4. 新开普通 Claude/Codex 对话。

通过标准：原有与新保存内容仍在；普通对话不恢复旧的全局主题绑定。测试完可停用测试偏好，保留 A/B 供问题定位。
