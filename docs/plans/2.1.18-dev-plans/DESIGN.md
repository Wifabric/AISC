# 界面方案草案

沿用现有视觉体系，实施前将 U 项结论写回这里。此文件描述可评审的交互，不是已经生成的界面。

| 位置 | 拟调整 | 空态/错误/窄屏 |
| --- | --- | --- |
| 文件侧栏重命名输入 | 保留现有内联输入，提交后显示实际最终条目名 | 冲突错误留在操作位置，保留输入；恢复失败显示实际路径 |
| 工作记录菜单 | 测量后贴近点击点，必要时向上/向左；子菜单同样避让 | 视口过短可滚动，所有动作仍可键盘触达；不裁到屏幕外 |
| 磁盘与缓存镜像行 | 删除、重命名、重建相邻；名称对话框可编辑完整引用 | registry:port/tag 及长名换行；错误不以固定 `-renamed` 重试 |
| 重建确认 | 目标机器、镜像、影响容器、缓存开关，默认无缓存 | 运行容器提示名称/状态；未支持 Remote 时说明并禁用，不能暗中构建本机 |
| 重建进度 | 两入口共用 BuildProgress，阶段+日志+取消+终态 | 无法确定完成则显示未知/失败，不静止在“完成”；重试保留目标 |
| 扩展市场推荐 | 单项推荐保持；新增“基础模块”区域/入口，科研/开发为待确认首发 | 模块摘要列种类与数量，详情列成员来源、状态、编辑/应用/卸载 |
| 模块操作预览 | 明确将安装、移除、保留及其原因；逐项进度与失败重试 | 长列表内部滚动；离线可编辑定义，在线操作说明不可用原因 |

交互重点：重复点击不会重复构建/安装；关闭页面不会被误解为删除数据；耗时操作有明确目标和归属，返回的新状态不污染另一个工作区。
