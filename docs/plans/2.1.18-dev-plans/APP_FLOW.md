# 用户流程

以下为本版已确认流程，U-1–U-3 按 D-13、U-4 按 D-17；实现与验收结果见发布准备。现有来源见 [reading-map](reading-map.md)。

## 文件与工作记录

文件侧栏 → 选中条目 → 重命名输入最终名称 → 后端校验身份/范围/冲突 → 文件系统完成 → 刷新列表及缓存。失败保留原条目，若两步改名恢复失败则显示可恢复的实际路径，不能虚报原名仍在。

工作记录侧栏 → 右键 → 按当前视口实测菜单尺寸定位 → 操作/展开子菜单 → 关闭并恢复焦点。滚动、缩放、窗口改变时重新计算或关闭，不能让菜单留在过期位置。

## 镜像命名与重建

设置 → 磁盘与缓存 → 目标镜像行 → 重命名 → 输入完整引用/查看默认建议 → 校验 → 确认旧 tag 处理 → 执行 → 按实际 tags 刷新列表。

镜像行“重建”或启动摘要“重建” → 显示目标机器与镜像引用 → 重新 inspect → 列出引用容器 → 有运行容器则停在提示页 → 用户自行停止后重试预检查（已确认，D-13）→ 确认已有镜像重建、默认勾选无缓存 → 共用 BuildProgress → 成功重新 inspect 后刷新；失败/取消展示错误并保留旧镜像。

构建中切换工作区不得把旧任务进度投射到新目标。重复点击同一目标不产生第二个并发构建。镜像不存在时明确显示“创建/构建”事实，不伪装成清理过旧镜像。

## 扩展模块

扩展市场 → 推荐 → 保留单项推荐列表，增加模块入口 → 模块详情 → 编辑成员/另存自定义模块 → 保存定义。保存和删除定义不直接触发安装或卸载。

模块详情“应用” → 对当前运行目标重新读取安装事实 → 展示安装、保留、认证前提 → 确认 → 逐项调用现有安装通路 → 显示 x/y 与每项终态 → 失败项重试。安装完成而未认证的 MCP 必须继续提示待认证。

“卸载” → 计算共享/预装/归属未知项 → 展示将移除与将保留的成员及原因 → 确认 → 逐项移除 → 刷新真实状态和关联记录。模块清单变更后再次应用只做本次差异，不能顺手卸载清单中已移出的旧成员。

## D-11 新增扩展修复流程

b7：插件市场选择明确来源 → 安装并显示操作状态 → 以真实清单确认结果；若请求超时，先核对终态再允许安全恢复，不能自动重复安装。

b8：已安装 GitHub MCP → 配置入口 → 选择目标引擎 → 用户本人完成授权/填写配置 → 保存并刷新 → 独立验证真实连接；取消/失败保留旧配置，秘密不进入展示与诊断。

b9：搜索 grill → 选择结果 → 独立加载详情 → 成功显示简介/来源；无简介与读取失败分别提示，后者可重试，迟到结果不跨查询或工作区显示。

b10：操作失败 → 当前提示与诊断历史 → 关闭仅隐藏当前展示 → 新失败产生新提示；关闭不改变操作状态或删除历史。

## 个人能力与主题（D-17 / S16）

标签栏菜单 → 个人能力与主题 → 设置我的回答偏好 → 模板副本/空白能力 → 名称、规则、启用 → 保存新版本 → 我的能力查看历史。修改规则生成新版本；恢复旧版同样生成新版本；之后的新会话读取已启用版本，旧会话保持原快照。

围绕一个主题持续做事 → 新建主题 → 目标与引擎 → 创建并开始主题对话 → 检查/编辑开场草稿 → 填入对话，由用户发送。普通 Claude/Codex 新会话不继承最近主题；回答偏好与主题独立。

主题页 → 目标、继续入口、相关对话、总结/手册/成果。当前主题对话状态条 → 更多 → 详情/重试/停止记录；停止保留已有记录，之后不再采集。普通对话不显示其他主题诊断，原始记录与历史默认收起。
