# 用户流程

以下为拟实现流程；涉及 U 项的分支须裁定后定稿。现有来源见 [reading-map](reading-map.md)。

## 文件与工作记录

文件侧栏 → 选中条目 → 重命名输入最终名称 → 后端校验身份/范围/冲突 → 文件系统完成 → 刷新列表及缓存。失败保留原条目，若两步改名恢复失败则显示可恢复的实际路径，不能虚报原名仍在。

工作记录侧栏 → 右键 → 按当前视口实测菜单尺寸定位 → 操作/展开子菜单 → 关闭并恢复焦点。滚动、缩放、窗口改变时重新计算或关闭，不能让菜单留在过期位置。

## 镜像命名与重建

设置 → 磁盘与缓存 → 目标镜像行 → 重命名 → 输入完整引用/查看默认建议 → 校验 → 确认旧 tag 处理 → 执行 → 按实际 tags 刷新列表。

镜像行“重建”或启动摘要“重建” → 显示目标机器与镜像引用 → 重新 inspect → 列出引用容器 → 有运行容器则停在提示页 → 用户自行停止后重试预检查（推荐，U-2）→ 确认已有镜像重建、默认勾选无缓存 → 共用 BuildProgress → 成功重新 inspect 后刷新；失败/取消展示错误并保留旧镜像。

构建中切换工作区不得把旧任务进度投射到新目标。重复点击同一目标不产生第二个并发构建。镜像不存在时明确显示“创建/构建”事实，不伪装成清理过旧镜像。

## 扩展模块

扩展市场 → 推荐 → 保留单项推荐列表，增加模块入口 → 模块详情 → 编辑成员/另存自定义模块 → 保存定义。保存和删除定义不直接触发安装或卸载。

模块详情“应用” → 对当前运行目标重新读取安装事实 → 展示安装、保留、认证前提 → 确认 → 逐项调用现有安装通路 → 显示 x/y 与每项终态 → 失败项重试。安装完成而未认证的 MCP 必须继续提示待认证。

“卸载” → 计算共享/预装/归属未知项 → 展示将移除与将保留的成员及原因 → 确认 → 逐项移除 → 刷新真实状态和关联记录。模块清单变更后再次应用只做本次差异，不能顺手卸载清单中已移出的旧成员。
