# b11 命令折叠 — 证据

- **branch**：`2.2.0-b11-command-fold`（基于 `2.2.0-wangyuncepu-integration`，含 b10）
- **范围（D-9 子目标 2/3）**：在 b10 渲染管线之上加「长命令/代码块折叠」。
  折叠/展开只作用于 `code` 块，不重新解析引擎文本，不改 b10 的解析规则；
  默认（无折叠状态）输出与 b10 基础渲染逐字节一致。
- **验证日期**：2026-11-28

## 结论

在 `workbench/src/features/terminal/markdownRender.ts` 上做纯增量：

- 新增 `TerminalRenderOptions { folded?: ReadonlySet<number> }`：折叠状态由调用方
  持有，元素是 `code` 块的序号（0 起，只在 code 块之间计数），渲染器保持纯函数。
- 新增 `toggleCodeFold(folded, codeBlockIndex)`：返回新 Set，切换单个代码块折叠，
  不修改入参（便于 UI 保存状态后再渲染）。
- `renderTerminalMarkdown(input, options?)`：
  - 未折叠代码块 → 与 b10 完全一致的 `── lang ──` + 原文代码 + `──────`。
  - 折叠代码块 → 单行 dim 摘要 `── lang (N lines, folded) ──`（N 为代码行数；
    单行显示 `1 line`），代码正文不输出。
  - `text` / `list` 块渲染完全不变；不输出折叠状态的块不受影响。
- 无插件注册/扩展点，深度保持最小：只对 `code` 块加折叠，不触碰 `parseTerminalMarkdown`。
