## UI 现在显示什么

1. **当前节点**（高亮卡片，位于最上方）：`代理组` / `节点` / `延迟` 三项；
   自动选择类策略组额外提示「该策略组自动选择节点」。
2. **选择代理组**：下拉列出 `list` 返回的全部策略组；切换后当前节点卡片与组内节点列表
   随之切换。
3. **组内节点**：仅显示当前组节点，逐行 radio 可选并显示该节点延迟（`未测` / `N ms` /
   `连接超时`）；每行有「测延时」；「使用节点」把选中节点应用到当前组，
   自动策略组禁用。

## 手测（四要素）

**前置**：Workbench 已启动；目标工作区以 proxy 模式运行且订阅包含至少一个可选策略组
（可选择时优先用包含 `Selector` 的订阅）；打开「网络与用量」标签，订阅已配置。

**步骤**：
1. 在「代理节点」区点击「刷新代理节点」，等待列表返回。
2. 观察顶部「当前节点」卡片：应显示当前策略组名、该组 `now` 节点名、延迟（初始为「未测」）。
3. 在「选择代理组」下拉中切换到另一个策略组：当前节点卡片与「组内节点」列表同步切换，
   且列表只包含新组的节点。
4. 在「组内节点」中选中一个非当前节点，点击「使用节点」；等待返回后当前节点卡片更新为该节点。
5. 对当前节点所在行点击「测延时」：该行与当前节点卡片的延迟变为毫秒数（或「连接超时」）。
6. 切到一个自动选择类策略组：确认「使用节点」按钮禁用，并显示自动选择提示。

**理想结果**：三层信息顺序为 当前节点 → 代理组 → 组内节点；当前节点卡片字段齐全
（代理组/节点名/延迟）；切组与选节点后当前节点卡片即时联动；延迟按节点独立显示。

**异常判定**：列表为空时显示空态文案；代理不可控时显示后端返回的错误；自动组允许测延时
但不允许手动选择；切工作区后旧组/旧延迟不残留。
