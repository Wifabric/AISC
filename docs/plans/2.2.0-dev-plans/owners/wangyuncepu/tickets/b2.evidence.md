## review 修复：恢复离线 catalog

- 发现（Spec review，possible creep）：SPEC 仅要求清空技能/MCP/插件，保留
  gh/npm/codex/claude；但实现顺带把**离线 marketplace catalog**也移出了镜像
  （`claude-plugins-official` 插件目录 + `known_marketplaces.json`），会破坏
  离线 marketplace 搜索/安装。这与 devlog 记录的 b10 教训（清空出厂安装时误
  清掉唯一 marketplace）相同。
- 修复范围：只撤销「catalog」部分删除，技能/MCP/插件保持清空。

### 恢复（catalog）
