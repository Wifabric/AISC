  - `container/_bundle/skills/gstack/`（7 个文件）

- `vendor/checksums.txt`：按 `git ls-files -- container` 重算（1355 条，校验通过）。
- `tools/check-docs.sh`：移除已删除的 `container/commands` 路径引用（`bash tools/check-docs.sh` → 50 passed, 0 failures）。
