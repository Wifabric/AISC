## 新反馈明细

### #44 扩展市场技能搜索后安装报错（bug / blocker）

- 来源：`issues/20261127-扩展市场技能搜索后安装报错-Thomas/反馈.md`
- 原始描述：技能搜索后点「安装本组已显示的 xx 项」仍报错 `installed 0/53; mattpocock/skills:setup-matt-pocock-skills: skill group source preflight failed`；展开子技能点安装后，侧边栏一直「安装中」（进度条宽度超出外框）、无报错、不能取消、卡住。
- 期望：① 无论 AISC 或宿主机是否配代理都能正确安装；② 安装情况显示在扩展市场界面而非侧边栏；③ 支持取消安装。
- 验收线（已定）：配代理能装 + 无代理清晰报错/可重试/可取消；「无代理也能装（离线源）」转期。
- 关联项：索引 #42（同名，2.1.20 已解决，疑似复发/未覆盖「整组安装」路径）、#13。

### #45 Provider 官方直连设置报错（bug / blocker）

- 来源：`issues/20261127-Provider官方直连设置报错-Thomas/反馈.md`
- 原始描述：直接启用切换报错 `provider switch codex-official failed (exit 0): …已切换到供应商 'codex-official'…注意：请重启 CLI 客户端`；点刷新报同样错。
- 期望：刷新应删除所有官方配置，然后可重新配置并登录 Codex 客户端。
- 验收语义（已定）：沿用 2.1.19「重新应用当前配置」，只修报错本身。
- 关联项：索引 #26、#34、#35（2.1.20 重做 Provider 后引入）。

### #46 安装默认给 claude/codex 装技能（ux / normal）

- 来源：`issues/20261127-安装默认会给claude和codex安装-Thomas/反馈.md`
- 原始描述：安装会默认给 claude/codex 装技能；希望镜像从今起不配默认技能、MCP、插件，全部清空（含之前残余的 gstack 等）。
- 期望：所有扩展配置全部通过扩展市场。
- 清空边界（已定）：只清技能/MCP/插件，保留 gh/npm/codex/claude 工具。
- 关联项：需求 #2、#6。

### #47 侧边栏文件/资源管理器左边只保留刷新（ux / normal）

- 来源：`issues/20261127-侧边栏文件折叠资源管理器左边只保留刷新-Thomas/反馈.md`
- 原始描述：侧边栏文件/资源管理器左边只保留「刷新」，删除「新建文件/新建文件夹」；但刷新应刷新对应标签内容（文件管理器=文件列表，工作记录=工作记录内容），原刷新按钮删除；新会话出现时应自动刷新工作记录，而非手动点。
- 关联项：索引 #32、#14。
- 已定（/to-spec）：新会话自动刷新用「实时 push」。

### #48 网络代理刷新节点 UI 重组（ux / normal）

- 来源：`issues/20261127-网络代理刷新节点有问题-Thomas/反馈.md`
- 原始描述：网络与用量点「刷新节点」后信息庞杂、主线不突出。
- 期望：突出当前节点（所属代理组、节点名、延迟）；代理组可选；组下节点可选且带延迟。
- 关联项：索引 #36。

### #49 工作记录打开超链接报错（bug / blocker）

- 来源：`issues/20261127-工作记录打开超链接报错-Thomas/反馈.md`
- 原始描述：工作记录预览点超链接报错「无法打开链接：文件可能已移动，或不在当前工作区内」；链接失效后仍是超链接，应在预览中删除超链接。
- 关联项：索引 #39。

### #50 工作记录预览 UI（斜杠/compact 拆开）（ux / normal）

- 来源：`issues/20261127-工作记录预览UI存在问题-Thomas/反馈.md`
- 原始描述：斜杠调用技能把 Skill 内容直接当作用户话发给 agent；实际用户发的是「斜杠命令 + 我提供的对话」。预览应把用户提供的内容作为提问显示、Skill 内容放进「思考与执行」；`/compact` 后 `/compact` 与回复被并作用户发送内容，需拆开整理。
- 关联项：索引 #39。

## 非目标（本阶段不做什么）

1. 不新增产品线或引擎类型（仅维护 Claude / Codex / Bash 三引擎）。
2. Provider 不做架构级重构——只在现有官方直连上修 #45，不动 Provider 数据模型。
3. 需求 #5 限「终端输出可读性」（Markdown/代码折叠/路径点击），不做公式 LaTeX 渲染、不引入插件式渲染扩展点。
4. 安装器继续不做代码签名。
5. #44「无代理也能安装」的离线源/镜像内置方案转期——本版只做到「配代理能装 + 无代理清晰报错/可重试/可取消」。
