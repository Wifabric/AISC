# 长对话无法恢复——复现取证协议

> 状态：**待用户提供复现样本**（v2.1.9 起挂账，2026-09-19 随 target 入 v2.1.13）。
> 挂账原因不是没人修，而是缺外部证据：无样本无法定位根因（archive/2.1.9-dev-plans/opt-batch-spec.md:181）。

## 需要用户收集的样本

1. **哪条会话**：标题 / 打开时间 / 所在工作区。
2. **规模**：消息数量级、大致上下文长度、期间是否触发过 compact。
3. **症状**：从哪恢复（历史会话面板？重启后自动恢复？）+ 精确报错（截图 / toast 文案 / 终端输出）。
4. **证据导出**：Workbench doctor 页的诊断导出包；若可取，容器内对应会话的 rollout 文件（`~/.codex/sessions/` 下该会话 jsonl）一并留档。
5. **复现步骤**：从打开 Workbench 到失败的最短操作序列。

## 拿到样本后

- 按 vibe-coding-skill Focused 路径立项：根因定位 → 修复 → 回归验证（同规模长会话 resume 通过 + 历史面板打开不崩）。
- 若样本显示与「历史会话重构 / 工作记录」（history-worklog.md）数据层同源，合并立项避免两处动同一链路。
