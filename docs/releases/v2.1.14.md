# AISC Workbench v2.1.14

> **正式版**（v2.1.14-preview.1 至 preview.5 五轮迭代验证后发布）。

## 本版亮点（相对 v2.1.13）

### 自更新体验
- 静默升级完成后**自动拉起新版**（升级链跑完即重启）
- 下载暂存文件按目标版本命名并自动清理
- 下载进度显示为 **MB 格式 + 可视进度条**
- PATH 注册表恒 `REG_EXPAND_SZ`（存量装机升级即自愈）

### Provider 管理
- 模板模式下模型映射/模型目录**随首次保存生效**（此前静默丢弃）
- 手填端点不再被模板清单/切换格式静默改写
- 拉取模型：无效 Key 直接报「API Key 无效或被上游拒绝（HTTP 401）」
- codex 编辑不再出现 UNIQUE 数据库错误
- 当前 provider 卡片改边框高亮（无常驻角标）

### 界面
- claude 高级槽位间距修复
- 历史页徽标/按钮胶囊统一对齐（含长标题省略）
- 「关于」弹窗字号放大不再越界（内部滚动）
- 工作区选择页窄窗口不再整页缩小
- codex 新建 provider 上下文窗口默认 1M（原 128k）

### 终端
- `Ctrl+/` 在 codex 的 `/btw` 旁路与主线间往返切换
- `Ctrl+Alt+hjkl/方向键` 为分屏焦点移动可用路径

### 工作区
- 顶栏一键「关闭工作区」回到选择页（运行环境清理，窗口保留）

### 构建与网络
- npm 主包/yazi 预置入仓——GitHub 全阻可离线构建
- 构建失败给出网络归因与三条出路
- `GH_PROXY`（versions.env）成为正式显式代理通道

## 安装 / 更新

- **v2.1.13 用户**：应用内「检查更新」（本次含大载荷 292MB，下载已修复超时问题）
- **v2.1.14 preview 用户**：应用内「检查更新」即可
- **全新安装**：双击 setup（自动引导 Docker/Python/WebView2 依赖）
- 覆盖更新：配置与工作区完整保留；升级链自动重建工作台镜像（预留约 10-30 分钟）

## CLI 更新通道

- Workbench 用户：随安装器自动更新（CLI 0.1.2）
- pip 用户：`pip install -U aisc-cli`（PyPI 独立发版）
