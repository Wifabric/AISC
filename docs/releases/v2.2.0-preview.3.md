# AISC Workbench 2.2.0-preview.3

这版 Preview 修复 preview.2 实测的 4 条 FAIL（T1/T2/T3/T6），并补 2 条实测中提出的增强（markdown 导入、子技能树形 UI）。随包 CLI 随本轮改动跟进。验收清单见 [HANDTEST](https://github.com/Wifabric/AISC/blob/v2.2.0-preview.3/docs/plans/2.2.0-dev-plans/HANDTEST.md)。

- **工作记录实时 push（T1）**　Claude/Codex CLI 直接 `/new` 或聊天后，新会话经 PTY 输出节流推送自动刷新工作记录，不再需要手动点刷新（此前只在 Workbench 内新建会话时触发）。
- **网络节点（T2 前半）**　当前节点信息与代理组/节点选择拆成两块面板；「使用节点」在可选手动选择的组内不再默认置灰。出站模式（规则/全局/直连）、系统代理、TUN、测全部延迟按钮转下一版（U-2）。
- **扩展市场（T3）**　整组安装改用 canonical `repo:directory` spec（cc-switch 回退行 `id` 只含 repo 时不再发裸 repo）；子技能按目录首段树形展开/折叠，父级与子级视觉区分。
- **终端 Markdown 视图（T6）**　标题/粗体/行内码渲染对齐工作记录预览；视图可选中复制；MD↔原视图切换停在底部同一位置，不再跳到不同堆结果。
- **markdown 导入（T5 增强）**　工作记录新增「导入 Markdown」，选一个本地 `.md`（来自其它 AISC 工作记录）即作为未归档区一条新会话，可用现有预览查看。

## 安装并核对版本

下载本页的 `AISC-Workbench-2.2.0-preview.3-setup.exe` 与 `.exe.sha256`。从 2.1.19 升级路径已由 CI 覆盖（升级保留设置/历史/工作区 + 卸载清理）。真实 Windows 复测 T1/T2/T3/T5/T6 仍待进行；出站/系统代理/TUN/测全部延迟转下一版。
