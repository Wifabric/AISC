# AISC v0.2.0

随 AISC Workbench `2.1.18` 提供的 CLI 功能版本。新增模块管理、个人能力和主题会话服务，保持 serve protocol 4，不改变现有 JSON envelope 契约。

## 变更

- 提供用户模块定义、逐项预检、缺项安装和受保护卸载；安装状态按工作区/运行目标隔离。
- 支持 GitHub MCP 按引擎配置认证和只读握手检查，保留用户自定义配置，不把保存状态当成访问验证。
- 扩展安装使用目标锁、独立等待预算和超时后状态核对；技能详情支持实际子目录与合法名称匹配。
- 新增个人规则的不可覆盖版本历史、启停、恢复和新会话快照注入。
- 主题会话显式绑定到单个 session，普通新会话不继承全局主题；采集缺失/截断时暂停，停止时保留历史并限定采集边界。
- 修复本地/远程文件改名冲突保护和大小写名称保持；支持镜像指定旧 tag 重命名、本机重建预检与进度。
- 工厂基础技能固定来源，补装缺失内容并保留用户修改和双引擎状态。

## 兼容性与发布

- 推荐与 Workbench `2.1.18` 配对使用；新功能需要当前 CLI，serve protocol 仍为 4。
- CLI 源码版本为 `src/aisc/VERSION`，独立发布标识为 `cli-v0.2.0`；Workbench 使用 `v2.1.18`。
- 正式 PyPI 上传与公开资产校验在发布批准后执行；此说明不表示已经上传。
- 独立 pip 包不含镜像构建资源；本版正式渠道不提供独立 CLI 归档。构建需要配套源码/资源或 Workbench bundle，不能将 pip 安装成功视为 `bundle fetch` 已有对应在线资产。
