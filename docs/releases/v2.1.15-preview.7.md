# AISC Workbench v2.1.15-preview.7

> **Preview hotfix**（develop 分支预发布，prerelease）。
> 本跳修复 preview.6 更新链路、Work Records 中文/折叠/去 Activate、Claude 树与 Docker 资源统计。

## 相对 v2.1.15-preview.6

### 更新

- GitHub releases / raw VERSION / setup / sha256 请求按 system proxy → direct 双策略重试。
- 设置 → 关于与更新分别显示：
  - Workbench GUI 当前 / 最新
  - 内置 CLI 当前 / 安装包内版本
- GUI 或 CLI 任一落后即提示更新；同一个 Workbench installer 会一并替换 GUI 与本机内置 CLI。

### Work Records

- Windows remote serve 按 UTF-8 读取 JSON frame，中文会话 / Collection 重命名保真。
- Collection 与未归档区可整体折叠。
- 移除 Activate 状态与自动收容；新会话默认进入未归档会话。
- Claude resumed/forked 同名会话按历史 `session_id` 识别 parent-child。
- 会话删除与 Collection 删除使用自绘确认框，不调用系统 native dialog，因此无系统提示音。

### Docker 资源

- 修复 Docker verbose JSON 中 `"false"` 字符串被当作 true 的问题；build cache 可回收统计与 df 恢复一致。
- Cache inspect 中同一 image ID 的多个 repo tag 聚合为一行，可回收只计一次。
- mirror 拉取基础镜像并打 bare tag 后，自动移除同 ID mirror alias，避免 Docker Desktop 出现 `node` 与 `docker.1ms.run/library/node` 双行。
- 通过 RootFS layer 前缀证据识别 AISC 构建引入的基础镜像，纳入安全管理；不会按名称误删用户自己的 node 镜像。
