# AISC v0.1.5.dev0

内部 preview 配对版本，用于 Workbench v2.1.15 后续 preview 验证。

## 变更

- Work Record ledger 支持 Collection / member / unfiled 持久排序与原子移动。
- Codex `history_base.thread_id` fork 来源会输出为 `parent_thread_id`，UI 可按父子树展示。
- Workbench workspace target 绑定与远端路由修复配套。

## 发布状态

该版本仅用于 preview / TestPyPI 验证，不发布正式 PyPI。
