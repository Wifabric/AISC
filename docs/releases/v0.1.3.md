# AISC v0.1.3

CLI 修复与功能累积发布（与 Workbench v2.1.14 同周期的全部 CLI 侧变更）。

## 修复

- **构建网络保底**（v2.1.14 b6）：npm 主包/yazi 预置离线安装（GitHub 全阻可构建）；保守分支 glob 修复（cc-switch 预置不再因版本号硬编码而漏配）；下载超时 60→300s；统一 GH_MIRRORS 镜像链；构建失败网络归因诊断（`build.failed` 事件附 `diagnostics` + 三出路建议）；`GH_PROXY`（versions.env）正式通道（空值零注入，手工编辑 = 显式同意）
- **拉取模型透传修复**（b9）：`cc-switch fetch-models` 此前只转发 `{"api_key"}`，添加态内联探测的 `base_url`/`template_id` 被丢弃 → 适配器空 stdin 报错；改为全量透传
- **serve 池白名单修复**（b10）：`cc-switch templates` 操作此前不在 serve 池允许清单中，Workbench 发起的模板清单拉取两版以来恒被拒绝、静默回退内置清单；白名单已补
- **serve 会话门修复**（2.1.13）：`session terminate`/`list` 改子命令白名单，关闭终端页签不再被静默吞（产生僵尸会话）

## 新功能（2.1.13 顺带）

- `conversation read`：聊天式只读对话查看器
- `worklog` 账本：会话开/关钩子 + `list`/`reconcile` 子命令（fail-open）
- `maintenance container-action` / `image-rm` / `image-tag`：Docker 资源管理（仅限 owned 资源，锁内重扫判权）
- `aisc run` 防重入守卫
