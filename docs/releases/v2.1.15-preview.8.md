# AISC Workbench v2.1.15-preview.8

> **Preview hotfix**（develop 分支预发布，prerelease）。
> 本跳修复 preview.7 的 Help/About 语义、fit 诊断弹层、更新 API 限流与磁盘缓存展示口径。

## 相对 v2.1.15-preview.7

### Work Records

- 新建 Work Record 默认折叠。
- 保留标题、成员数与手动展开行为，已有记录的展开状态不变。

### 帮助菜单

- 「运行诊断」：打开原环境诊断对话框。
- 「帮助文档」：打开 AISC README。
- 新增「关于 AISC Workbench」弹窗，展示：
  - Workbench 版本
  - AISC CLI / Bundle 版本
  - Workbench 镜像版本
  - Claude Code 版本
  - Python 版本
  - 平台信息

### 终端

- 移除「fit 诊断（网格 5s 内 ≥6 次变化）— 截图反馈」自动弹层。
- 正常终端 fit / resize 逻辑不变。

### 更新

- 实测 GitHub API 返回 403 时响应头为 `X-RateLimit-Remaining: 0`，属于未认证 API 配额耗尽。
- 更新检查改用 `https://github.com/Wifabric/AISC/releases.atom` 作为主通道。
- GitHub API 仅作为 Atom 失败时的 fallback。
- Release setup / sha256 URL 继续使用 GitHub Releases 稳定下载地址。

### 磁盘与缓存

- 移除 Docker 资源上方的旧 df 摘要和独立 cache inspect 区块。
- 「扫描 Docker 资源」同时执行：
  - Docker ownership scan；
  - itemized cache inspect。
- 统一展示：
  - 可管理容器 / 容器总数；
  - 可管理镜像（按 image ID 去重）/ 镜像总数；
  - 悬空归属镜像；
  - Build Cache 数量与可回收空间；
  - Volumes / Networks（仅报告，不清理）。
- 「清理」组合执行：
  - AISC owned/legacy 容器与镜像清理；
  - builder cache 与 dangling image 的 24h 过滤清理；
  - 重新扫描统一结果。
