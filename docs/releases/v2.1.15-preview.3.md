# AISC Workbench v2.1.15-preview.3

> **Preview hotfix**（develop 分支预发布，prerelease）。
> 本跳修复 preview.2 实测确认的远端 target 路由问题，并落地 Work Records 交互重构。

## 相对 v2.1.15-preview.2

### 远端路由

- 新增 workspace target binding：workspace 在 target 切换时立即绑定实际 Local/Remote target，后续 runtime/session 命令不再继承错误路由。
- `target_set` / `target_clear` 会同步当前 workspace；远端窗口 boot 不再等待第一次 runtime start 才固定路由。
- runtime / session / conversation / work-record / workspace mutation / watcher 全部按 workspace binding 路由。
- 移除业务路径对 process-global `ActiveTarget` 的直接读取；`runtime_poll_light` 在远端窗口禁用本机 Docker 直连。
- 新增 `target_route` 日志，可确认 `runtime.start` 与 `session.open` 实际 kind/machine。

### Work Records

- Codex CLI `/fork` 产生的 `history_base.thread_id` 会映射为 `parent_thread_id`，新会话自动 reconcile 并挂到父节点下。
- Collection、成员、未归档会话均支持持久排序；成员可在 Collection 与未归档之间拖拽移动。
- 移除 Work Records 内嵌「全部会话」入口。
- Collection 与会话重命名改为点击后在原名称处进入编辑态，不再常驻输入框。
- Collection 标题、状态与动作按钮同行同高；成员行与未归档行统一长标题 ellipsis 与视觉规格。
- 会话右键菜单支持恢复、删除、重命名、移入/移出。
- Collection 卡片可拖拽排序；顶部导航当前 resume 会话所属 Collection 自动切换 Active。
- CLI preview 版本升至 `0.1.5.dev0`。
