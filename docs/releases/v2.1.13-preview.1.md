# AISC Workbench v2.1.13-preview.1

> **Preview**（develop 分支预发布，prerelease——正式版需明确要求才发布）。
> 自更新载荷：Workbench NSIS 安装器（Windows x64），**自带本构建时最新 CLI**（装 UI 顺带装 CLI）。
> 本构建起 tag 版本号全形嵌入安装包（D-4 版本戳），阶段内 preview 迭代链自更新可达（2.1.12-preview.1 → 本版实测通过）。

## 本包亮点（相对 v2.1.12-preview.1）

- **聊天式只读对话查看器**：历史页悬停/右键「查看对话」——气泡式 transcript 回放，思考与工具调用折叠可展开，向下懒加载分页；严格只读，输入仍走容器会话
- **历史页按 agent 分组**：claude / codex 都有历史时分组展示（组头+条数，最近使用的组在上）；单 agent 保持原平铺
- **终端恢复链闭环**：加载早期输出在满窗/超限场景结构性失效根治（保最早内容、行对齐裁剪）；静默吞 terminate 的 session 门改子命令白名单——close-tab 不再产生僵尸会话
- **provider 切换后 resume 修复**：切换 provider 后恢复旧 codex 会话不再报 `Model provider 'X' not found`——对话自动切换到当前 provider 继续
- **资源管理器可滚动**：文件多时不再看不到下方内容
- **Docker 资源管理**（D-12）：容器启动/停止/删除、镜像删除/重命名，仅限 aisc 自有资源，unverified 只读
- **worklog 账本**（批 8）：`aisc worklog list/reconcile` 记录会话开/关与 resume 关系，fail-open 不阻塞会话
- **详细检测精细化 + 免责文案中文化**：Docker 资源检测含镜像类明细

## 安装 / 更新

- 全新安装：双击 setup 即可（自动引导 Docker/Python/WebView2 依赖）
- 覆盖更新：直接安装，配置与工作区完整保留；升级链会自动重建工作台镜像（预留约 10-30 分钟）
- **自更新实测通过**：2.1.12-preview.1 装机 → 「检查更新」→ 下载确认 → 静默升级，数据与镜像链全链验证

## CLI 更新通道

- Workbench 用户：随本安装器自动更新（CLI 0.1.2：新增 `conversation read`、`worklog` 账本、provider resume 修复）
- pip 用户：`pip install -U aisc-cli`（PyPI 与本 release 独立发版）

## 已知事项

- 静默升级完成后不会自动拉起新版（需手动打开）；staging 临时文件名沿用旧版本号——两处 UX 优化随下批
- 「工作记录」概念（历史会话聚合）按用户裁决移入待解决池，需求捋清后立项
