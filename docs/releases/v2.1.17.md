# AISC Workbench v2.1.17

> 正式版（2026-11-01 `v2.1.17-preview.2` 统一实测通过后发布）。

## 扩展生态与界面

- 修复常驻 serve 调用 `extensions updates-check` 的旧 CLI 空 envelope；协议错误返回
  完整 JSON，真实失败可诊断且不自动吞错。
- 已安装 MCP/插件补齐真实描述；市场技能详情按需读取上游 SKILL.md，同名跨仓库不串。
- 技能组摘要、单项详情、长文本、窄侧栏与键盘焦点布局修正；市场和服务可重复操作。
- 官方 hosted GitHub MCP 默认进入 cc-switch 与 Claude/Codex live 配置；用户同名配置、
  开关和自定义 token 环境不被覆盖。

## 更新、安装包与镜像

- 更新下载校验后记录 receipt；新版本启动复验并只清理自有成功安装包。
- 交互式更新改为“退出后打开目标架构 setup.exe”；取消、失败和无关下载不误删。
- NSIS 按宿主目标架构打包 x64/arm64 offline payload，安装包体积明显缩小。
- Yazi 官方 release 按架构 digest/size 锁定；打包前强校验目标架构离线闭包。
- 镜像内置 Node 26.13.0、Codex 0.166.0、Claude Code 2.1.314、cc-switch 5.11.3、
  Mihomo 1.19.33、Yazi 26.9.1；随 Workbench 提供 CLI `0.1.10`。

## 会话与工作记录

- 工作记录分支沿用原会话 preflight/resume 链路，只创建 fork，不改写原会话。
- 分支启动失败只回收失败标签，保留可读错误；成功新会话自动归入来源记录。
- 记录分组提供按既有引擎新建会话入口；单会话右键移除通用新建入口。

## 文件管理

- Windows Explorer 复制/粘贴走真实 CF_HDROP；应用内保留受控路径回退。
- Explorer 支持 Ctrl/Shift/Ctrl+A 多选、批量复制/粘贴/删除、确认与部分失败明细。
- 粘贴目标规则明确：选中目录进目录，文件/空白进父目录；冲突不覆盖。
- 文件与目录可多选拖入 Bash/CLI，按稳定顺序安全转义且不自动执行。
- 本地/远端路径按各自文件面处理，Rust 再次校验来源与目标 containment。

## 验证

- B1–B6 本地全门禁、生产 Workbench 构建与 Workbench/Bundle/NSIS/Artifact 远端流水线通过。
- `v2.1.17-preview.2` 用户统一实测 B1–B6，结论无问题。
- release 分支 Workbench CI 通过；最终 main/tag 构建与 Release 资产核验见发布记录。

## 安装 / 更新

- preview 用户：应用内「设置 → 关于与更新 → 检查更新」，或从 GitHub Release 下载
  `AISC-Workbench-2.1.17-setup.exe`。
- 全新安装：运行 NSIS setup，按界面引导准备 Docker、Python 和 WebView2 依赖。
