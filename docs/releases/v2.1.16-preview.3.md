# AISC Workbench v2.1.16-preview.3

> **Preview hotfix**（develop 分支预发布，prerelease）。
> 本版修复 v2.1.16-preview.2 第二轮实测反馈的扩展交互、MCP 安装、服务合并、出厂技能与远程镜像问题。

## 相对 v2.1.16-preview.2

### Skills / MCP / Plugins

- Smithery MCP 详情改用 HTTP `deploymentUrl` 生成 MCP 配置，修复搜索后安装无结果的问题。
- MCP 安装默认对 Claude 与 Codex 同时启用。
- Skill 安装默认对 Claude 与 Codex 同时启用。
- Skill 更新使用独立 `skill-update` 操作，保留用户已有的启停状态。
- 操作完成 / 失败显示全局 toast。
- 操作进度条改为“动作 + 目标 + x/y + 横向进度条”，不再与按钮 spinner 重复显示两个旋转图标。
- 子技能行：
  - C / X / 更新 / 卸载按钮固定在最右侧；
  - 技能说明在按钮下方整行显示；
  - 再次点击子技能收起说明，但父仓库组保持展开。
- 三个市场搜索框清空时立即清除旧结果。

### 远程镜像兜底

不默认使用代理；直连失败后才重试镜像：

- skills.sh 搜索：
  - `https://skills.sh/api/search`
  - `https://www.skills.sh/api/search`
- Smithery：
  - `https://registry.smithery.ai`
  - `https://api.smithery.ai`
- GitHub git 操作（skill repo / skill install / plugin install / plugin update / plugin marketplace add）：
  - 直连 `github.com`
  - `https://ghfast.top/https://github.com/`
  - `https://gh-proxy.com/https://github.com/`

### Services 与宿主工具

- 「宿主工具（F2）」从设置独立分组迁入左侧「服务」视图。
- 服务视图同时包含：
  - 宿主工具白名单管理
  - Web Services / gateway 状态
- 设置页不再显示独立宿主工具入口。

### 磁盘与缓存

- 删除第一层“容器（aisc 相关）/ 镜像（aisc 相关）”资源名重复列表。
- 保留：
  - 汇总卡片
  - 后方容器 / 镜像管理表
