# AISC v0.1.7.dev0

内部 preview 配对版本，用于 Workbench v2.1.15 后续远程工作区验证。

## 变更

- 新增 serve `fs.roots` op：Windows 返回权限内所有盘符，POSIX 返回 `/`。
- `fs.watch` 接受 Windows drive-letter workspace root，远端实时文件变更不再退化为轮询。
- 保持 serve protocol 4；`fs.roots` 为 additive 能力，旧 Workbench 可继续使用既有 fs ops。

## 发布状态

该版本仅用于 preview / TestPyPI 验证，不发布正式 PyPI。
