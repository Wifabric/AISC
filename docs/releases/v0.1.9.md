# AISC v0.1.9

正式发布版本，随 AISC Workbench v2.1.16 提供，并同步发布到 PyPI。

## 变更

- Work Records：新增只读预览、层级拖拽、创建 / 分支、加载占位与同名会话级联删除数据面。
- 扩展数据面：新增 skills / MCP / plugins 统一 adapter，支持列表、启停、安装、卸载、更新、市场检索、插件市场与来源冲突快照。
- Smithery MCP 安装使用 HTTP `deploymentUrl`；skill 安装默认 Claude / Codex 双启用，更新保留用户启停状态。
- 无宿主代理链路：skill archive 探测 + ghfast / gh-proxy Git 暂存；cc-switch GitHub API resolver 支持 gh-proxy fallback；构建基础镜像按源轮转预拉。
- Docker 维护：Build Cache 全量清理、AISC 相关资源扫描、Node 基础标签清理与 24 小时悬空资源安全窗。
- 构建事件与 Docker 冷启动诊断稳定化；tests 矩阵收敛为 pytest。
- 保持 serve protocol 4。

## 兼容性

- Workbench v2.1.16 及后续版本推荐使用本版本。
- 旧 Workbench 通过 serve protocol hard gate 提示升级远端 CLI。

## 发布状态

正式 PyPI 发布版本。
