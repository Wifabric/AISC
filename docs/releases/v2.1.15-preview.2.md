# AISC Workbench v2.1.15-preview.2

> **Preview hotfix**（develop 分支预发布，prerelease）。
> 本跳集中修复 v2.1.15-preview.1 实测暴露的阻断问题。

## 相对 v2.1.15-preview.1

- **修复会话打开崩溃**：`session open` 的 `fork_session` 参数现在贯通 CLI command 层与 application 层；新建 bash / claude / codex 会话不再触发 `open_session() got an unexpected keyword argument`。
- **远端配对升级**：serve wire protocol 3→4，CLI 开发版本升至 `0.1.4.dev0`。旧 `0.1.3` 远端会在握手阶段明确提示升级，不再出现半配对的 PTY 无输出状态。
- **Work Records 树状修复**：collection 内 Codex child 默认折叠到 parent 下，展开后只出现一次；未归档会话同样按树状组织。
- **Work Records 溢出修复**：长标题省略号截断，缩进由行首引导线承担，恢复/移出按钮保持在所属卡片边界内。
- **恢复链路回归**：Work Records 成员恢复继续走 preflight → provider tab 链路，配套组件测试覆盖。

## 远端升级要求

- 远端仍运行 CLI `0.1.3` / serve protocol 3 时，本版会明确拒绝配对。
- Windows/WSL 远端需升级到 CLI `0.1.4.dev0` / serve protocol 4。可安装本 Workbench preview，或使用后续 TestPyPI `0.1.4.dev0` 包。
