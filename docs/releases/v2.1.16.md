# AISC Workbench v2.1.16

> **正式版**（preview.1–preview.4 四轮实测反馈后发布）。

## 本版亮点（相对 v2.1.15）

### Work Records

- 新增 Work Records 只读预览、父子拖拽、创建 / 分支入口与加载占位。
- 同名会话删除时级联清理 ledger 与 transcript，不残留引用缺失。
- Work Record 右键菜单支持移动、重命名与测试 / Test 目标语义合并。
- 会话树展示、折叠与未归档管理更贴近实际工作流。

### 扩展管理

- Provider 与 Extensions 迁入左侧导航；顶部导航仅保留 bash / codex / claude。
- 新增 Skills / MCP / Plugins 统一管理：
  - 查看、安装、卸载、更新、启用 / 禁用；
  - Skill / MCP / Plugin 市场检索与链接安装；
  - Smithery MCP 市场、skills.sh 技能市场、Claude 插件市场；
  - Skill 仓库分组与子技能单独操作；
  - 独立与插件来源冲突提示；
  - 操作进度、完成 / 失败 toast 与稳定批量进度。
- Skill 安装默认 Claude + Codex 均启用；更新保留用户启停状态。
- 出厂安装 `grill-me` 与 13 个 `caveman-*` 技能，全部默认双引擎启用。
- MCP 删除改用 PTY 安全确认；Smithery 安装使用 HTTP `deploymentUrl`。
- 更新按钮与卸载按钮动画按操作类型区分，不再同时转动。

### Docker 与磁盘

- 设置 → 磁盘与缓存提供容器 / 镜像 / 悬空镜像 / Build Cache / Volumes / Networks 统一资源面板。
- 一键清理输出压缩为简明结果，移除重复资源名列表与估算噪音。
- Build Cache 使用 `builder prune --force --all` 全量清理，并移除当前 Node 基础镜像标签。
- 悬空镜像与未使用容器保留 24 小时安全窗。
- AISC 相关镜像包含 `super-claude` 与 `node` 基础镜像。
- 构建缓存清理后同步移除 Node 基础标签，避免“已清理但仍显示可回收”。

### 构建与无代理兼容

- Docker 冷启动基础镜像按镜像源轮转预拉，每源 120 秒，无需手工 `docker tag`。
- apt 使用清华源，npm 使用 npmmirror。
- mihomo / geodata / cc-switch / yazi 支持 release 镜像与本地预置。
- cc-switch release resolver 在直连 GitHub API 失败或限流后重试 `gh-proxy.com` API 镜像。
- Skill 安装先探测 GitHub archive HEAD；直连失败时通过 ghfast / gh-proxy shallow Git clone 暂存，再走 cc-switch 官方 install / sync。
- 不默认启用系统代理。

### 更新链路

- Workbench「关于与更新」检查与下载支持无宿主代理镜像兜底。
- GitHub API 可回退 `gh-proxy.com`；release asset、sha256 与 raw `VERSION` 可回退 `ghfast.top` / `gh-proxy.com`。
- 下载始终校验 SHA256，失败安装包不落盘。

### 终端与稳定性

- bash / claude / codex 普通拖选自动进入宿主剪贴板；Codex mouse tracking 下无需 Shift。
- 关闭工作区后租约释放，重新进入同一工作区不再被“启动已被阻断”卡住。
- factory npm 与 runtime toolchain 分离，`claude-real` / `codex-real` 不再因挂载遮蔽丢失。
- Codex / Claude 自更新落到持久 toolchain，重启 runtime 后版本不回退。
- tests.yml 收敛为 pytest，九组矩阵稳定运行。

## CLI

- 随 Workbench 提供 CLI `0.1.9`。
- pip 用户可独立安装 `aisc-cli==0.1.9`。
- CLI 包含 Work Records 数据面、扩展 adapter、Docker 资源维护、构建事件与无代理镜像兜底改进。
- serve protocol 保持 4。
