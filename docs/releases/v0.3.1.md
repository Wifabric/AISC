# AISC v0.3.1

此版本更新 Workbench 2.1.20 所用的 CLI、运行时与容器资源。远程主机也应使用相应版本，才能获得新的会话和工作记录操作。

- 保留已配置的 Provider，识别官方直连入口。节点列表区分手动切换与自动选择，遇到订阅或控制组件尚未生效时提供诊断。
- 改进市场搜索结果获取，固定首装 office-hours 所需的代码与 Bun。镜像使用本版资源重新构建后生效。
- 改进会话工作目录、集合成员查询和已打开会话的终止匹配。容器中升级 Codex 后，新旧标签可分别使用所需版本的程序文件。

Workbench 安装器内置本版 CLI 和配套 bundle。独立分发名为 `aisc-cli`，命令为 `aisc`。正式索引上线后可用 `pipx install aisc-cli==0.3.1` 安装，再运行 `aisc version --format json` 核对。独立 wheel 不含 Docker 构建资源；设置 `--aisc-root` 时请提供匹配版本的资源目录。
