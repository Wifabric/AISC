# AISC Workbench v2.1.18

本次更新提供技能、MCP、插件与个人能力的初步使用环境，并修复扩展安装、文件操作和界面反馈问题。随 Workbench 提供 AISC CLI `0.2.0`，保持 serve protocol 4。

## 扩展与基础模块

- 离线预装 caveman、grill-me、grilling 和 Karpathy 通用技能，来源固定并保留许可；升级补齐缺少项，保留用户修改及原有启停状态。
- 扩展市场保留单项推荐，提供科研基础与开发基础模块。模块成员在线安装；支持复制、编辑、保存和删除用户模块定义。
- 应用模块只补装缺少项；卸载只移除模块引入且不再共享的成员，保护预装、归属不明和用户修改的内容。删除定义不会顺带卸载扩展。
- 插件安装使用独立等待预算和目标进程锁，超时后核对真实状态，避免重复安装或把未知结果报成成功。插件通路当前支持 Claude。
- GitHub MCP 可按 Claude/Codex 分别配置本人凭据，明确区分已保存、握手和实际工具访问；取消操作不会更改配置。
- 修复技能子目录详情读取、连字符名称匹配和加载/空内容/失败状态；失败可重试，切换查询不串用旧详情。
- 扩展错误可关闭，同次错误不立即重复弹出；新失败仍提示，工作区之间隔离状态。

## 个人能力与主题

- 新手入口区分“设置我的回答偏好”和“围绕一个主题持续做事”。偏好可从模板创建副本，保存规则、启停和版本历史；恢复旧版会生成新版本。
- 回答偏好独立应用于新 Claude/Codex 对话；普通新对话不自动关联最近主题。
- 从主题入口创建的对话只关联该主题，提供可编辑开场草稿，由用户检查后发送。已有对话的上下文不被后台强行替换。
- 主题页集中展示目标、继续入口、相关对话、总结和成果；技术诊断与历史默认收起。
- 状态条仅展示当前主题对话。源记录缺失或截断时暂停同步并保留已存记录，支持关闭提示、重试或停止后续采集。
- 旧的工作区全局主题选择停用，原主题、个人能力版本、手册与成果保留。

## 文件、镜像与操作体验

- 文件/目录仅大小写改名保留精确名称；本地和远程同名冲突均不覆盖原目标。
- 工作记录右键菜单及子菜单按窗口边界避让，支持小窗口滚动与键盘关闭。
- 镜像可编辑完整名称，默认 `super-claude:` 加 8 位字母数字；成功后仅移除选中的旧 tag，保留其他 tag。
- 本机镜像重建共享预检与进度，运行容器会阻止重建，不自动停删。默认无缓存，可选择缓存；远程入口明确禁用。

## 开发协作与验证

- 开发 Skill、WIKI 和贡献者流程统一职责：贡献者完成必要开发/测试后提交 PR，主开发者整合、修正小问题，并统一生成 Preview 和验证。
- Preview.13 已由用户确认验收通过；自动化、真实数据面、候选 GUI、跨平台构建和安装验证分别留有证据。
- 安装/升级前保存正在编辑的内容。正式资产、校验值和已知验证边界以发布记录为准；发布准备文档不等于已经创建 Release。
