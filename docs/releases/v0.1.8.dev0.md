# AISC v0.1.8.dev0

内部 preview 配对版本，用于 Workbench v2.1.15 后续 Work Records 与远程中文修复验证。

## 变更

- Windows frozen serve 从 `stdin.buffer` 按行读取并按 UTF-8 解码，远程 Work Record / 会话中文标题不再被本地代码页破坏。
- Claude resumed/forked 会话从历史 `session_id` 提取 parent thread id，Work Records 可按父子树展示。
- Work Records reconcile 移除 Active 自动收容，新会话保持未归档。
- Docker build 成功通过 mirror 拉取基础镜像并打 bare tag 后，会移除同 ID mirror alias。
- Docker 资源扫描/明细修复字符串布尔值解析、同 ID image tag 聚合，并通过 layer 前缀证据管理 AISC 构建基础镜像。
- 保持 serve protocol 4。

## 发布状态

该版本仅用于 preview / TestPyPI 验证，不发布正式 PyPI。
