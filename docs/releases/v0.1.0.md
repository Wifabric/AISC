# AISC v0.1.0

首个公开发布：三轨分发成型——Windows Workbench 安装器 / 三平台 CLI 便携包与 PKG / **PyPI（`pipx install aisc-cli`）**。

## 安装与获取

- **pip 渠道（本版首发）**：`pipx install aisc-cli`——分发名 `aisc-cli`，命令名 `aisc`。需自备 Docker；pip 安装不含构建资源，`aisc build` 前先 `aisc bundle fetch`，详见 README。
- **安装器/便携包**：本 Release 页 `AISC Workbench_0.1.0_x64-setup.exe` / 三平台 CLI 档案（`AISC-0.1.0-*`）及 `.sha256` / `SHA256SUMS`。

## 0.1.0 周期要点

- **CLI**：`aisc bundle fetch/list/remove/path`（数据根 bundle 库，API digest 校验 fail-closed）；`aisc update`（冻结形态自更新，rename dance 原子替换 + 回退副本 + `--pin-tool` 工具版本钉选，更新结构性不碰用户 pin）
- **Workbench**：设置页 Docker 资源管理（扫描/清理/重建，扫描前置门）；构建失败一键重建；主题切换深色残留修复；应用自更新（检查/下载 sha256 校验/静默安装）
- **平台与镜像**：Node 基底升 22（claude-code 2.1.273 要求）；cc-switch 统一 v5.10.4；CLAUDE/CODEX 版本作为 build args 进构建管线
- **分发架构**：见 `docs/adr/002-pypi-distribution.md`（三轨、六级资源解析链、瘦 wheel 路线、fetch 信任模型）

## 兼容性

0.x Alpha：命令、配置与持久化契约仍可能变化（破坏性变更将升 minor 并在 notes 声明）。`aisc doctor` 新增 channel/platform 检查辅助多渠道并存诊断。
