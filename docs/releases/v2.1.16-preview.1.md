# AISC Workbench v2.1.16-preview.1

> **Preview**（develop 分支预发布，prerelease——正式版需明确要求才发布）。
> 自更新载荷：Workbench NSIS 安装器（Windows x64），自带当前源码构建的 CLI sidecar `0.1.9.dev0`。

## 本包亮点（相对 v2.1.15）

### 扩展统一管理

- 左侧导航新增「供应商」与「扩展」视图；顶部终端 Tab 只保留 bash / codex / claude。
- 扩展页提供技能 / MCP / 插件三页签：
  - 已安装项单行展示，左侧展开详情，右侧保留启停、更新与卸载。
  - 技能支持 Claude / Codex 独立启停。
  - MCP 支持 stdio/http 配置导入、删除与 Smithery 市场搜索安装。
  - 插件提供官方市场、搜索、安装、更新与卸载。
- 技能商城支持 skills.sh 检索与一键安装；同一仓库的技能在已安装与搜索结果中聚合为一行，展开后可单技能操作，也可批量启停、更新、安装或卸载。
- 插件与 Skill 来源冲突可见；独立安装与插件内置同名技能会提示并存来源。
- 安装 / 卸载 / 更新过程显示按钮级进度动画。

### CLI 更新与运行时

- 修复容器内 npm 自更新 `EEXIST` 与 project bind mount 上的 Codex 自更新 `EACCES rename`。
- codex / claude 更新落在持久 toolchain；重启 runtime / 工作区后版本保持。
- Codex wrapper 通过容器内 shadow 副本运行，更新仍写入持久 prefix，避开 Windows bind mount 的运行中目录锁。
- 出厂 Skills 与 Plugins 默认清空，由用户按需从市场安装。

### 终端与剪贴板

- bash / claude / codex 选中文本自动写入宿主系统剪贴板。
- Codex 开启 mouse tracking 后，普通左键拖选也能生成 xterm 选区并自动复制，不再必须 Shift+拖选。
- Codex 右键菜单「复制」可用；未移动的单击仍回放给 Codex TUI。

### Docker 与磁盘

- 设置页提供统一 Docker 资源卡片与扫描结果。
- 「清理构建缓存」执行 `docker builder prune --force --all`，清理后 Build Cache 归零。
- 清理时同步移除当前 Node 基础镜像标签；悬空镜像仍保留 24 小时安全窗，不影响容器与其它正常镜像。
- Docker 冷启动构建按镜像源链预拉 Node 基础镜像，每源最多 120 秒并自动切换，无需手工 `docker tag`。
- 镜像扫描纳入 AISC 相关 Node 基础镜像，并按 image ID 聚合避免重复计数。

### Work Records

- 左键会话打开只读预览，不再误触发恢复。
- 父节点拖拽时子节点跟随。
- 支持新建会话与分支会话入口，操作后列表即时刷新。
- 会话加载期显示加载中，消除「引用缺失」闪现。
- 删除会话时级联清理同名未显示会话，并在确认框中给出数量。

### 稳定性

- 修复关闭工作区后租约未释放导致的「启动已被阻断」。
- 修复 Provider/扩展视图被 services 空态泄漏破坏的问题。
- 修复工厂 npm 目录被 project toolchain 挂载遮蔽导致 `claude-real` / `codex-real` not found。
- cc-switch 升级至 5.11.3；resolver 钉版时严格消费对应 exact 离线资产。

- 全新安装：双击 setup 即可。
- 覆盖更新：直接安装，配置与工作区保留；也可从 v2.1.15 经「设置 → 关于与更新 → 检查更新」升级。
- 内置 CLI 为 `0.1.9.dev0`，另以 `cli-v0.1.9.dev0` 发布到 TestPyPI 配对验证。

## 已知边界

- Smithery 与 skills.sh 市场依赖外部网络；源站不可达时会显示明确错误。
- 插件市场安装的插件内容由各自上游提供，安装前请自行确认信任来源。
- `清理构建缓存` 会删除全部派生构建缓存并移除当前 Node 基础镜像标签；下次构建会重新预拉基础镜像。
- macOS / Linux Workbench bundle 仍为 CI 验证通道，本 preview 的自更新载荷以 Windows NSIS 为准。
