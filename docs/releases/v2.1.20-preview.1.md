# AISC Workbench 2.1.20-preview.1

这版 Preview 供 Windows 用户集中验收 11 条反馈。随包 CLI 为 **0.3.1.dev0**。验收步骤覆盖从 2.1.19 升级、现有工作区及新建会话。[逐项验收清单](https://github.com/Wifabric/AISC/blob/v2.1.20-preview.1/docs/plans/2.1.20-dev-plans/HANDTEST.md)

- **供应商**　升级迁移保留已配置、已选用或已加入故障转移的旧预置。Claude、Codex 分别合并等价的官方直连入口，自建配置保留名称与操作。
- **代理与设置**　刷新失败时显示订阅或控制组件的具体状态。设置中的网络与用量按订阅、节点、供应商与模型分区，可分别刷新。
- **技能市场**　选择 office-hours 时只安装该技能及运行所需的共享文件与依赖。GitHub 技能归档下载失败时可以继续尝试 Git 获取。
- **终端**　改进 Claude、Codex 在启用鼠标跟踪和滚动后的文本框选，松开鼠标后按当前设置复制选区。
- **工作记录**　技能与工具详情可折叠，支持打开工作区文件和网址。记录右键及预览页均可导出完整 Markdown 并选择保存位置。删除记录或集合时弹窗说明影响范围。
- **新建会话**　标签栏与工作记录集合共用目录输入及会话类型菜单。输入路径只提示匹配文件夹，从集合发起的引擎会话沿用所选目录和集合。

## 安装并核对版本

下载本页的 `AISC-Workbench-2.1.20-preview.1-setup.exe` 和 `.exe.sha256`。安装后核对 Workbench 版本。测试供应商迁移和容器内技能时，使用本版配套资源构建镜像并重启测试工作区。独立 CLI 稳定渠道仍为 0.3.0。

开发回归覆盖旧供应商配置、真实 Mihomo 节点切换、隔离容器安装上游 office-hours、真实 xterm 选区事件，以及长中文记录完整导出。原反馈数据库、在线技能市场与真实账号对话、系统剪贴板、原生保存窗口和 SSH 桌面操作仍待整版实测。偶发卡死按上版决定暂缓。
