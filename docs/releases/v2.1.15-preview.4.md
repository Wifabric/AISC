# AISC Workbench v2.1.15-preview.4

> **Preview hotfix**（develop 分支预发布，prerelease）。
> 本跳修复 preview.3 字段反馈：Windows 远端 PTY、远端目录浏览、Work Records 溢出/删除联动、更新检查体验。

## 相对 v2.1.15-preview.3

### Windows 远端

- 修复 PyInstaller CLI 在 SSH stdio 管道下 `serve --stdio` 无 ready / 无 PTY 输出：
  - 不再调用会阻塞的 frozen TextIO `reconfigure()`；
  - stdin 从 binary buffer 按行 UTF-8 解码；
  - stdout frame 通过 OS descriptor 写出。
- 远端 workspace 路径支持 Windows drive letter（如 `C:/Users/admin/project`）。
- 远端目录浏览从对应机器的 home 开始，支持进入、返回、选择；drive-letter 当前输入可直接打开。
- CLI preview 版本升至 `0.1.6.dev0`。

### Work Records

- 长标题行和卡片宽度受左侧栏约束，标题 ellipsis，不再横向溢出。
- 右键删除会话后同步移除 ledger member，列表立即消失，不再残留「引用缺失」。

### 更新

- 更新检查完成后保留「再次检查」按钮；结果显示 current/latest/note，网络失败可重试。
