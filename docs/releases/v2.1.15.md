# AISC Workbench v2.1.15

> **正式版**（preview.1–preview.8 八轮实测反馈后发布）。

## 本版亮点（相对 v2.1.14）

### 远程工作区

- 修复 SSH 远端会话阻塞、PTY 无输出与 Windows frozen serve 管道问题。
- 支持远端全盘资源导航：Windows 可切换 `C:/`、`D:/`、`E:/` 等盘符，POSIX 从 `/` 开始。
- 远端文件侧边栏首次打开即加载，实时 watcher 支持 Windows drive-letter workspace。
- Recent workspaces 按「机器 + 路径」识别；同一路径在本机与不同远端互不合并。
- Workbench 数据面按 remote workspace target 路由；provider、cc-switch、会话记录、Work Records 与 runtime 信息来自远端。
- 控制端 remoteMachines、窗口布局与 UI 设置保留本机，保证远端连接可控。

### Work Records

- Work Record / Collection 与未归档会话支持树状组织、折叠、拖拽排序、右键菜单与内联重命名。
- Claude 与 Codex resumed / forked / subagent 会话均按 parent-child 展示。
- 移除 Active 自动收容；新会话默认进入未归档区，手动加入 Work Record。
- 中文 Work Record 与会话标题保真。
- 删除确认改为应用内静默对话框，不触发系统提示音。
- 删除会话后 ledger 与 transcript 同步清理，不残留“引用缺失”。

### 终端与 UI

- bash / codex / claude 会话退出后直接关闭对应标签。
- 修复 CLI 输出滚动抢回视口问题，保留用户手动回看所有权。
- 修复 fit 自动诊断弹层，不再出现“网格 5s 内 ≥6 次变化”提示。
- 帮助菜单拆分为「运行诊断」「关于 AISC Workbench」「帮助文档」。
- About 弹窗展示 Workbench、CLI、bundle、镜像、Claude Code、Python 与平台版本。

### 更新

- 更新检查分别报告 Workbench GUI 与内置 CLI 当前 / 最新版本。
- 一个 Workbench installer 一并升级 GUI 与本机内置 CLI。
- GitHub API 限流时自动改用 releases.atom 主通道，API 仅作 fallback。
- 下载与 sha256 sidecar 支持 proxy / direct 多策略重试。

### Docker 与磁盘

- 设置 → 磁盘与缓存合并为单一 Docker 资源面板。
- 同步展示 ownership scan 与 itemized inspect：容器、镜像、悬空镜像、Build Cache、Volumes、Networks。
- 镜像按 image ID 聚合，同 ID 的 `node` 与 mirror repo tag 不重复计数。
- 修复 Docker verbose JSON 字符串布尔值解析，Build Cache 可回收统计恢复正确。
- 通过 RootFS layer 前缀证据安全管理 AISC 构建基础镜像，不按名称误删用户 node 镜像。
- 一键清理组合执行 AISC 资源清理、builder cache / dangling image 清理并重新扫描。
- 构建后清理同 ID mirror alias，避免 Docker Desktop images 出现重复行。

## CLI

- 随 Workbench 提供 CLI `0.1.8`。
- serve protocol 保持 4。
- pip 用户可独立安装 `aisc-cli==0.1.8`。

## 安装 / 更新

- v2.1.14 或 v2.1.15 preview 用户：应用内「帮助 → 检查更新」。
- 全新安装：双击 NSIS setup，自动引导 Docker / Python / WebView2 依赖。
- 远端机器需安装 CLI `0.1.8` 或直接安装 Workbench v2.1.15。
