# AISC v0.1.10

正式发布版本，随 AISC Workbench `v2.1.17` 提供，并同步发布到 PyPI。

## 变更

- extensions argparse 全链传播 JSON envelope；未知 op、缺参和非法字段不再退回
  stderr-only 空输出。
- `updates-check` 面对旧 CLI 空输出时提供可诊断恢复路径，保留显式覆盖与真实失败。
- serve filesystem 支撑 Workbench 文件管理的本地/远端统一文件面、containment、
  有界递归复制、不覆盖粘贴和逐项失败结果。
- 更新健康诊断继续区分 CLI/bundle 配对、显式覆盖和兼容性缺失。
- 保持 serve protocol 4。

## 兼容性

- Workbench `v2.1.17` 及后续版本推荐使用本版本。
- 旧 Workbench 继续通过 serve protocol hard gate 提示升级远端 CLI。

## 发布状态

正式 PyPI 发布版本。
