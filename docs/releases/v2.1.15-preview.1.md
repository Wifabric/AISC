# AISC Workbench v2.1.15-preview.1

> **Preview**（develop 分支预发布，prerelease——正式版需明确要求才发布）。
> 自更新载荷：Workbench NSIS 安装器（Windows x64），自带当前源码构建的 CLI sidecar。

## 本包亮点（相对 v2.1.14）

- **远程会话稳定**：SSH runtime 的 lease heartbeat/release 使用 claim 时机器快照，不再随全局 target 漂移；runtime 停止时显式释放 lease。
- **Windows 工作区去重**：仅大小写或分隔符不同的路径折叠为同一历史身份，同时保留用户原显示形态。
- **终端滚动修正**：CLI 输出与协议响应不再抢走用户回看视口；跟踪/回看边界可预期。
- **PTY 断流修复**：Docker PTY pump 将临时 timeout/EINTR 继续等待，不再误判为 EOF；长时间输出保持可达。
- **Work Records / Collection**：会话记录与轻量集合语义落地，支持 active 自动收容、手动加入/移出、归档、重命名、删除、运行成员终止与物理级联删除；删除失败会逐项提示。
- **Work Records UI 重构**：操作符号化；会话右键支持查看、恢复、重命名、分支和删除；Codex 子代理按 parent-child 树状折叠展示；搜索命中 child 时保留父级路径。
- **History 并入**：独立 History 侧边栏入口移除，「全部会话」内嵌到 Work Records，并保留搜索、只读查看、恢复、重命名、删除能力。
- **会话退出收口**：bash/codex/claude 自行退出时直接关闭对应标签；分屏只移除退出 pane，失败/断链仍保留现场。
- **UI 边界**：顶部 bash/codex/claude 状态栏不再作为分屏/面板拖拽边界。

## 安装 / 更新

- 全新安装：双击 setup 即可（自动引导 Docker/Python/WebView2 依赖）。
- 覆盖更新：直接安装，配置与工作区保留；也可从 v2.1.14 装机经「设置 → 关于与更新 → 检查更新」升级。

## 已知边界

- Codex CLI 无原生 fork：Work Records 中 Codex 会话的「分支」菜单保持禁用，不做 rollout 手工改写。
- Claude fork 已有全链路自动化覆盖；本轮可用工作区无 Claude transcript，实机样本待 preview 日常使用回归。
