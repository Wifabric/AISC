# AISC Workbench v2.1.14-preview.1

> **Preview**（develop 分支预发布，prerelease——正式版需明确要求才发布）。
> 自更新载荷：Workbench NSIS 安装器（Windows x64），**自带本构建时最新 CLI**（装 UI 顺带装 CLI）。

## 本包亮点（相对 v2.1.13-preview.1）

- **自更新体验三项**（2.1.13 转期收口）：静默升级完成后**自动拉起新版**（升级链跑完即重启，不再「什么都没发生」）；下载暂存文件按目标版本命名并自动清理；PATH 注册表恒 `REG_EXPAND_SZ`（存量装机升级即自愈）
- **provider 新建保真**：模板模式下模型映射/模型目录**随首次保存生效**（此前静默丢弃）；手填端点不再被模板清单/切换格式静默改写；「拉取模型」修复——添加页内联探测（base_url/模板端点候选透传）、无效 Key 直接报「API Key 无效或被上游拒绝（HTTP 401）」；模板清单 serve 门两版潜伏故障修复（此前恒回退内置清单）；codex 编辑不再出现 UNIQUE 舞步报错；codesome-v3 原生端点对齐 `/v1`
- **UI 对齐四项**：claude 高级槽位间距、历史页徽标/按钮胶囊统一（含长标题省略）、「关于」弹窗字号放大不再越界（内部滚动）、picker 窄窗不再整页缩小
- **终端键盘域**：`Ctrl+/` 在 codex 的 `/btw` 旁路与主线间往返切换（xterm 映射缺口直发修复）；`Ctrl+Alt+hjkl/方向键` 为分屏焦点移动可用路径
- **关闭工作区**：顶栏「操作」菜单与状态栏旁按钮一键关闭当前工作区、回到选择页（确认后清理运行环境，窗口保留）
- **网络保底构建**：npm 主包/yazi 预置入仓（GitHub 全阻可离线构建）；下载超时与镜像链统一；构建失败给出网络归因与三条出路；`GH_PROXY`（versions.env）成为正式显式通道
- **provider 卡片**：常驻「使用中」角标改为边框/底色高亮，操作按钮悬浮显示

## 安装 / 更新

- 全新安装：双击 setup 即可（自动引导 Docker/Python/WebView2 依赖）
- 覆盖更新：直接安装，配置与工作区完整保留；升级链会自动重建工作台镜像（预留约 10-30 分钟）
- 2.1.13 装机可经「设置 → 关于与更新 → 检查更新」静默升级至本版，完成后自动重启

## CLI 更新通道

- Workbench 用户：随本安装器自动更新（CLI 0.1.2：构建网络保底修复、provider 探针透传、serve 门白名单补 templates）
- pip 用户：`pip install -U aisc-cli`（PyPI 与本 release 独立发版）

## 已知事项

- 完全物理断网（含国内源全阻）下构建仍会失败于 apt 段——属 D-17 裁定的已知边界（apt 离线化未立项）
- 保底预置边界为 x64（arm64 伴生包不入库，arm64 宿主走在线分支）
