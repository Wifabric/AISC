## 安装与获取

- **pip 渠道（本周期末上线）**：`pipx install aisc-cli`（推荐）——分发名 `aisc-cli`，命令名 `aisc`。需自备 Docker；pip 安装不含构建资源，`aisc build` 前先 `aisc bundle fetch`，详见 README。
- **安装器/便携包**：GitHub Release 页 `AISC Workbench_<版本>_x64-setup.exe` / 三平台 CLI 档案。
