# AISC Workbench 2.2.0-preview.2

这版 Preview 供 Windows 用户集中验收 10 条反馈（7 新 + 3 悬账）。随包 CLI 为 **0.3.2.dev0**。验收步骤覆盖从 2.1.19 升级、现有工作区及新建会话。[逐项验收清单](https://github.com/Wifabric/AISC/blob/v2.2.0-preview.2/docs/plans/2.2.0-dev-plans/HANDTEST.md)

- **扩展市场**　整组安装进度与取消移到扩展市场界面；单仓库源失败不阻塞同组健康仓库；无代理清晰报错、可重试、可取消。
- **Provider**　修复官方直连切换/刷新报错，沿用「重新应用当前配置」语义。
- **镜像**　默认不装技能/MCP/插件（留 gh/npm/codex/claude 工具），扩展全部走扩展市场。
- **侧边栏**　文件/资源管理器只留「刷新」，刷新作用于当前标签；新会话实时 push 自动刷新工作记录。
- **网络**　网络与用量节点 UI 重组：当前节点突出（代理组/节点名/延迟），代理组与节点可选。
- **工作记录**　失效超链接不报错、预览中降级为普通文本；斜杠调用与 /compact 在预览中拆开显示。
- **终端**　基础富文本渲染、长命令/代码块可折叠、路径可点击定位；公式 LaTeX 转期。
- **可观测性**　标签卡住加状态探针与日志，交付复现路径（不承诺本版修复）。

## 安装并核对版本

下载本页的 `AISC-Workbench-2.2.0-preview.2-setup.exe` 和 `.exe.sha256`。安装后核对 Workbench 版本。从 2.1.19 升级路径已由 CI 覆盖（升级保留设置/历史/工作区 + 卸载清理，本版修复卸载残留 `aisc-bundle`）。测试供应商迁移和容器内技能时，使用本版配套资源构建镜像并重启测试工作区。独立 CLI 稳定渠道仍为 0.3.0。

开发回归：Python 1912 / cargo 409 / vitest 968 / vue-tsc 0 / vendor 1355 全绿。真实 Windows 整版手测、真实账号对话、Docker 工作区实测仍待进行；公式 LaTeX 渲染与「无代理也能装（离线源）」转期。
