# AISC v0.1.6.dev0

内部 preview 配对版本，用于 Workbench v2.1.15 后续 preview 验证。

## 变更

- 修复 Windows PyInstaller CLI 在 SSH stdio 管道下 `serve --stdio` 不输出 ready / PTY frame 的问题：不再阻塞于 frozen TextIO reconfigure，stdin 按行读取 binary buffer，stdout frame 通过 OS descriptor 写出。
- 保持 serve protocol 4；本版本是同协议实现修复。

## 发布状态

该版本仅用于 preview / TestPyPI 验证，不发布正式 PyPI。
