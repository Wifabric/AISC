## 相对 v2.1.16-preview.3

- `caveman-explore`
- `caveman-help`
- `caveman-learn`
- `caveman-manage`
- `caveman-optimize`

继续叠加 `mattpocock/skills` 的 `grill-me`，共 14 个出厂技能；全部默认对 Claude 与 Codex 启用。非 `caveman-*` 前缀技能（如 `cavecrew`、`megacave`、`ultracave`）不进入出厂集合。

### 无宿主代理的 Skill 安装 / 更新

- 不默认启用系统代理。
- 先短超时探测 GitHub archive HEAD；直连可用时保留 cc-switch 原生安装。
- 直连不可用时，依次探测 `ghfast.top` / `gh-proxy.com`，并通过可达镜像执行 shallow Git clone。
- 由于 cc-switch 5.11 会自行拼 GitHub archive URL 且不尊重 Git `insteadOf`，镜像分支会先把 skill 暂存到 cc-switch source，再走官方 `skills install` / sync，保留 SSOT 语义。
- Skill 安装默认 Claude + Codex 均启用。
- Skill 更新会记录更新前启停状态，并在官方 install 后恢复，避免 cc-switch 默认只开 Claude。
- Host 侧 extensions adapter 超时从 200 秒提高到 600 秒，给镜像 clone / install 留出完整窗口。

### 扩展操作按钮动画

- 更新按钮仅在 `update` 操作进行中显示 spinner。
- 卸载按钮仅在 `remove` 操作进行中显示 spinner。
- 覆盖技能仓库组、单个技能、MCP、插件与市场安装入口；同一目标不再出现两个按钮同步转动。

### 关于与更新

不默认使用代理；直连失败后使用已验证镜像：

- GitHub Releases API：
  - `https://api.github.com/...`
  - `https://gh-proxy.com/https://api.github.com/...`
- Release asset / sha256 / raw `VERSION`：
  - 直连 GitHub
  - `https://ghfast.top/https://github.com/...`
  - `https://gh-proxy.com/https://github.com/...`
- HTTP 403 / 404 / 5xx 不再直接终止，会继续尝试下一候选。
- 下载仍强制校验 `.sha256`，失败安装包不落盘。

### 构建镜像无代理兼容

- cc-switch release resolver 在直连 GitHub API 网络失败 / rate limit 后，重试 `gh-proxy.com` API 镜像；显式 `AISC_GH_API_BASE` 不被覆盖。
- 新增构建网络静态契约，锁定 Dockerfile 与 stage 脚本的 GitHub mirror 链。
- 既有能力保留：apt 清华源、npm npmmirror、基础镜像预拉链、mihomo / geodata / cc-switch / yazi release 镜像与本地预置。
