# AISC Workbench v2.1.14-preview.2

> **Preview**（develop 分支预发布，prerelease——正式版需明确要求才发布）。
> 本版为 preview.1 的修复迭代（**自更新修复版**）：从本版起，应用内「检查更新」可正常下载大载荷安装包并全自动升级。

## 相对 v2.1.14-preview.1 的修复

- **自更新大载荷下载修复**：下载器沿用了订阅组件时代的 30 秒整体超时——292MB 安装包（preview.1 起含离线伴生包）必然在 ~30 秒处腰斩（表现为 ~33MB 处「参数无效」反复失败）。改为连接 10s + 读 60s 双超时（只掐停滞、不掐总时长），292MB 实测 61.2 秒完整拉取
- **全新装机 PATH 创建修复**：无用户 PATH 变量的机器上安装不创建 PATH（「值不存在」被误判为「读取失败」而跳过写入）——现正确创建 `REG_EXPAND_SZ`
- **CI/发布链修复**：vendor 校验账本随代码变更自动补齐；macOS 构建机 bash 3.2 兼容；NSIS 安装包补齐离线伴生包（GitHub 全阻可离线构建承诺现覆盖 Windows 安装器）

## 本包亮点（继承 preview.1，相对 v2.1.13-preview.1）

- 自更新体验三项（升级完成自动拉起 / 暂存按目标版本命名并清场 / PATH 恒 REG_EXPAND_SZ 存量自愈）
- provider 新建保真全套（模板模式映射随保存生效 / 拉取模型修复与 Key 拒绝直说 / 模板清单 serve 门修复 / codex 编辑 UNIQUE 修复）
- UI 对齐四项、终端键盘域（Ctrl+/ 切换、Ctrl+Alt 分屏导航）、关闭工作区回 picker、网络保底构建
- provider 卡片视觉（当前项边框高亮替代常驻角标）

## 安装 / 更新

- **v2.1.14-preview.1 用户**：本版应用内更新链已可用——「设置 → 关于与更新 → 检查更新」下载确认即可（下载不再中断，升级链完成后自动重启）
- v2.1.13 用户：建议浏览器下载本版手动安装一次（旧版应用内下载会被 30 秒超时腰斩，已在本版修复）
- 全新安装：双击 setup 即可；配置与工作区完整保留，升级链自动重建工作台镜像（预留约 10-30 分钟）

## CLI 更新通道

- Workbench 用户：随本安装器自动更新（CLI 0.1.2）
- pip 用户：`pip install -U aisc-cli`
