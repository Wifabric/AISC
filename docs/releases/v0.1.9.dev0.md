# AISC v0.1.9.dev0

`0.1.8` final 后的 v2.1.16 阶段内部开发版本，随 AISC Workbench
`v2.1.16-preview.1` 配对验证；仅发布 TestPyPI，不发布正式 PyPI。

## 变更

- Work Records：只读预览、拖拽层级、创建/分支入口、加载占位与同名会话级联删除链路完善。
- 扩展数据面：Skills / MCP / Plugins 统一管理，新增 skill/MCP/plugin 市场检索、
  安装卸载更新、插件官方市场、Smithery MCP 搜索与安装、Skill 仓库分组所需的
  directory 快照。
- 构建链路：Node 基础镜像预拉按 120 秒轮转镜像源；cc-switch resolver 钉版时
  只消费 exact asset，避免新 sha 配旧离线包。
- 磁盘维护：Build Cache 改为 `builder prune --force --all` 全量清理，并移除
  当前 Node 基础镜像标签；悬空镜像仍保留 24 小时安全窗。
- CLI 协议保持 develop 内部迭代，正式兼容发布待 `0.1.9` final。

## 发布状态

内部开发版本；发布到 TestPyPI 供 v2.1.16 preview 配对验证。
