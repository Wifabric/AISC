# AISC Workbench v2.1.16-preview.2

> **Preview hotfix**（develop 分支预发布，prerelease）。
> 本版修复 v2.1.16-preview.1 实测反馈的磁盘日志、扩展侧栏稳定性与出厂技能裁定。

## 相对 v2.1.16-preview.1

### 磁盘与缓存

- 移除常驻“可回收量为估算值…”说明。
- 清理 AISC / 清理构建缓存后只显示一行简短结果。
- 不再输出 `容器: 清除 0`、`镜像: 清除 0`、`builder: 无回收`、`dangling: …` 噪音。
- Docker 29 的 builder prune 不输出汇总时，按 df 前后差值回填实际清理量，避免把已清理的 Build Cache 误报为无可回收。

### 扩展侧栏

- 扩展内容随侧栏宽度收缩，不再横向撑开。
- Provider / Extensions 视图隐藏顶层“搜索文件”框；该搜索仅属于文件/产物面板。
- Skills / MCP / Plugins 的列表、loading、busy、搜索状态、错误与操作状态完全分离：
  - 技能安装不会让 MCP / 插件面板闪刷；
  - 切换页签不会丢失另一页签的安装进度。
- 三个市场搜索框清空时立即清除旧搜索结果。
- 仓库组与子技能展开状态分离：点击子技能显示介绍，再次点击不会折叠父组。
- 新增稳定操作进度条：显示“安装中 / 更新中 / 卸载中”、目标与 `x/y`；批量安装逐项推进。

### 出厂技能

- 按新裁定，安装 AISC 时通过既有 cc-switch 管理链路预装：
  - `grill-me`
  - `caveman`
- 其他技能仍通过扩展商城按需安装。
