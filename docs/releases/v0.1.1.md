# AISC v0.1.1

维护性发布：CN 网络构建韧性与发布流水线加固。

## 安装与获取

- **pip 渠道**：`pipx install aisc-cli`——分发名 `aisc-cli`，命令名 `aisc`。需自备 Docker；pip 安装不含构建资源，`aisc build` 前先 `aisc bundle fetch`，详见 README。
- **安装器/便携包**：本 Release 页 `AISC Workbench_0.1.1_x64-setup.exe` / 三平台 CLI 档案（`AISC-0.1.1-*`）及 `.sha256` / `SHA256SUMS`。

## 本版要点

- **cc-switch `downloads/` 预置口**（CN 网络构建韧性）：`container/downloads/` 预置的 cc-switch 资产在构建时优先使用（对齐 mihomo/npm/yazi 模式）；resolver 钉版分支对预置文件仍过 sha256 强校验——预置不降完整性。新增 `scripts/stage-cc-switch.sh` 预下载工具。
- **vendor-verify Windows CRLF 免疫**：工作树换行漂移不再造成全量 MISS。
- **发布流水线五连修**（v0.1.0 发布窗口实战）：sdist 薄形守卫（MANIFEST.in + 测试钉住）；pip-audit 环境审计；publish job 产物顺序；PyPI verify 裸版本号 + skip-existing 幂等重跑；SBOM `--out` 实参。
- **文档**：0.1.0 周期调研批交付（r1 provider 模板化 / r2 codex computer use，实施裁决门开放中）。

## 兼容性

0.x Alpha：命令、配置与持久化契约仍可能变化。工具版本钉选（`aisc update --pin-tool`）的用户层数据在升级中保留。
