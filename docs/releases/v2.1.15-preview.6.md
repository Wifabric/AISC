# AISC Workbench v2.1.15-preview.6

> **Preview hotfix**（develop 分支预发布，prerelease）。
> 本跳修复 preview.5 字段反馈：协议错误提示、远程 Explorer 首载、Recent 机器路由、Docker 同 ID tag 展示。

## 相对 v2.1.15-preview.5

### 设置 / 磁盘

- CLI 协议错误保留 `technical_detail`，明确显示类似：
  `serve protocol mismatch: client 4, remote 3 — upgrade the aisc CLI on the target machine`。
- Docker 可管理镜像按 image ID 聚合；同一 ID 的 `node:22-slim` 与
  `docker.1ms.run/library/node:22-slim` 显示为一行。
- 删除仍按 image ID，retag 默认使用第一条 repo ref。

### 远程工作区

- 修复首次打开远程 workspace 时 App watcher 与 Explorer watcher 的首载竞态；
  左侧文件导航不再需要手动刷新。
- workspace binding 保留配置机器名（如 `win-test`），不再降级成 `admin@10.147.20.7`。
- 旧 history 中的 `user@host` alias 会归一到配置机器名；第二次点击 Recent
  直接进入对应远端，不再误走本机。

### CLI 配对

- 本批未变更 Python CLI，Workbench 继续配对 CLI `0.1.7.dev0` / serve protocol 4。
- 实测中原 `wsl-base` 为 CLI `0.1.3` / protocol 3，已升级 TestPyPI
  `0.1.7.dev0`，ready banner 现为 protocol 4。
