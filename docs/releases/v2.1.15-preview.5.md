# AISC Workbench v2.1.15-preview.5

> **Preview hotfix**（develop 分支预发布，prerelease）。
> 本跳修复 preview.4 远程工作区模型反馈：全盘导航、机器身份、远端数据面取证、Help 反馈。

## 相对 v2.1.15-preview.4

### 远程资源导航

- serve 新增 `fs.roots`：Windows 返回权限内所有盘符，POSIX 返回 `/`。
- 远端目录浏览解除 `$HOME` 限制，可切换 `C:/`、`D:/`、`E:/` 等根目录。
- 浏览器支持盘符选择、面包屑、上一级、刷新、隐藏目录和搜索。
- SSH 远端无法调用本机原生 Explorer；本版本提供 SSH-native 等价导航，路径与权限均在远端解析。

### 工作区机器身份

- history 记录新增 `machine_name` / `machine_host`。
- Recent 按「机器 + 路径」去重、恢复、删除；同一路径在本机和不同远端是不同工作区。
- Recent 行显示具体驱动机器；菜单与 picker 都按记录机器打开。
- Windows 远端 watcher 接受 drive-letter workspace，并把 `\` / `/` 事件路径归一，实时刷新不再退化为轮询。

### 远端数据面与 Help

- provider / cc-switch / conversation / work-record / runtime 继续 remote workspace target 路由；cc-switch 增加 target_route 诊断。
- 控制端 remoteMachines、窗口和 UI 偏好仍保留本机，避免失去远端连接控制面。
- 帮助文档通过系统 opener 打开 `Wifabric/AISC` README。
- 检查更新显示 checking / 已最新 / 可更新 / 失败四态；发现新版本时直达设置页下载与安装引导。

### CLI

- CLI preview 版本升至 `0.1.7.dev0`，serve protocol 维持 4（`fs.roots` 为 additive 能力）。
- 旧远端 CLI 不支持 `fs.roots` 时，Workbench 降级为 home 所在根，不阻断兼容。
