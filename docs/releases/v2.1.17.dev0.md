# AISC Workbench v2.1.17.dev0

> Preview 发布说明草稿；当前尚未创建该标签或发布资产，待统一用户回归结论。

## 扩展生态与界面

- 改善无宿主代理时的技能组安装/更新、失败定位和仅失败项重试；长组操作不再阻塞 Services 控制面。
- Skills/MCP/Plugins 市场元数据缓存与更新提示；独立扩展市场提供六分类、各 10 条精选推荐。
- 推荐卡片内展开中文简介、来源和详情；已安装列表空态收敛，移除操作日记。
- 技能仓库与插件市场可维护；旧 runtime 缺少来源操作时给出升级说明。

## Work Record

- 静态阅读页面按问答排版，每轮思考/命令收拢为单项，可逐项展开细节。
- 支持 Markdown 表格、代码高亮、脚注、LaTeX、图片附件与受限本地文件/网站链接。
- 实时终端继续字节穿透；历史阅读不模拟输出阶段。
- 进程/隔离容器中止后保留 Codex/Claude 原生 resume ID，重试和配置引导不丢恢复身份。

## 更新、服务与镜像

- Windows 下载更新后保持应用运行；点击“退出更新”并确认后，Explorer 选中安装包并打开正常安装界面。
- 服务视图区分“宿主工具（F2）”“注册服务”，按端口排序，提供名称回退与双语状态。
- caveman 首次安装默认双引擎开启，内容更新保留用户显式关闭状态。
- 镜像锁版 Node 26.13.0、Codex 0.166.0、Claude Code 2.1.314、cc-switch 5.11.3、
  Mihomo 1.19.33、Yazi 26.9.1、geodata 20261030；随附 CLI 0.1.10.dev0。

## 验证边界

完整本地门禁、最终镜像三轮扩展数据面、三平台 sidecar/deb/dmg 和 NSIS 安装形态 CI 通过；
Windows CU 已覆盖市场/服务/历史阅读关键路径。Remote SSH、全局 Docker 引擎断连、
真实大历史、新锁版已认证恢复及其它故障环境项未全部执行，详见活动计划 CLOSEOUT-PRETEST。
本 preview 不代表正式 final 验收；测试发现的问题将在后续 preview 修复。
