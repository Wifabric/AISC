# AISC Workbench 2.1.20

Windows x64 桌面版，随包 CLI 0.3.1。首次使用请安装 Docker Desktop 并启动引擎，再打开 Workbench 选择工作区。

- **供应商与升级。** 在同一工作区从 2.1.19 升级，已经配置的第三方 Provider 保留。Claude、Codex 各自显示官方直连入口。遇到列表只有直连时，核对工作区绝对路径及 AISC 数据目录，两者共同决定读取哪份配置。
- **代理与用量。** 在设置的「网络与用量」刷新代理节点，手动组可切换节点，自动组显示当前选择。订阅更新后按页面提示重开代理模式工作区。Provider 和模型用量在各自表中显示，窄窗口可滚动到操作按钮。
- **技能市场。** 搜索按批显示，首屏 20 条；有更多结果时点「加载更多」，整组安装显示本次将安装的数量。搜索仍需联网。用本版资源重建镜像后，单选 `office-hours` 首次安装可使用随包资源及 Bun；显式更新仍访问上游。
- **终端。** 改进 Claude、Codex 多屏输出后的选中即复制、快速滚动和标签切换。容器内升级 Codex 后，新建标签可使用已升级版本。
- **工作记录。** 「思考与执行」可展开查看技能、命令、工具参数和输出。预览可打开有效文件和网址；右键记录或从预览底部可导出完整 Markdown。删除弹窗说明影响，拖入集合保留记录标题，删除集合时结束有关成员会话。
- **新建会话。** 标签栏和集合加号都可选择工作目录，支持含空格的子目录。由集合发起的 Claude、Codex 或主题的首个引擎会话归入该集合，Bash 在所选目录启动。

下载文件名为 `AISC-Workbench-2.1.20-setup.exe`，使用同页 `.exe.sha256` 校验。升级时保留应用数据，重新打开原工作区。节点控制、Codex 启动及离线技能资源需要用新 bundle 重建工作区镜像。独立 CLI 走 PyPI 渠道，纯 pip 安装需另备配套镜像构建资源。
