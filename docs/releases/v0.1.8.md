# AISC v0.1.8

正式发布版本，随 AISC Workbench v2.1.15 提供，并同步发布到 PyPI。

## 变更

- Windows frozen serve 从 `stdin.buffer` 按行读取并按 UTF-8 解码，远程 Work Record / 会话中文标题不再被本地代码页破坏。
- 新增 `fs.roots`：Windows 返回权限内全部盘符，POSIX 返回 `/`。
- `fs.watch` 支持 Windows drive-letter workspace，远端实时文件变更不再退化为轮询。
- Claude resumed/forked 会话从历史 `session_id` 提取 parent thread id，Work Records 可按父子树展示。
- Work Records 移除 Active 自动收容，新会话默认保持未归档。
- Docker build 通过 mirror 拉取基础镜像并打 bare tag 后，会移除同 ID mirror alias。
- Docker 资源扫描 / 明细修复字符串布尔值解析、同 ID image tag 聚合，并通过 layer 前缀证据安全管理 AISC 构建基础镜像。
- 保持 serve protocol 4。

## 兼容性

- Workbench v2.1.15 及后续版本推荐使用本版本。
- 旧 Workbench 通过 serve protocol hard gate 提示升级远端 CLI。

## 发布状态

正式 PyPI 发布版本。
