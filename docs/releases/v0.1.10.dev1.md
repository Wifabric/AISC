# AISC v0.1.10.dev1

> Preview 双轨发布，配对 Workbench `v2.1.17-preview.2`。仅发布 GitHub preview 与
> TestPyPI；正式 PyPI 的 final-only 门保持跳过。

## 变更

- extensions argparse 全链传播 JSON envelope；未知 op、缺参和非法字段不再退回
  stderr-only 空输出。
- `updates-check` 面对旧 CLI 空输出时提供可诊断恢复路径，保留显式覆盖与真实失败。
- serve filesystem 继续为 Workbench B6 提供本地/远端统一的文件面操作边界。
- 版本随 preview 修复链递增；无正式 Python API 承诺变化。
