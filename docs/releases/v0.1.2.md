# AISC v0.1.2

CLI 功能发布：run 防重入守卫 + Docker 资源只读逐项检测。

## 新行为（可能有感知）

- **`aisc run` 防重入**：工作区已存在**运行中**容器时，`aisc run` 拒绝执行
  （`AISC_ERR_CONTAINER_EXISTS`，exit 6）并给出进入/生命周期/多实例指引。
  此前同系列活容器会被静默复用、改名重建会围绕活容器进行、Workbench 运行时
  旁的 CLI 激活会静默堆叠容器——全部收归拒绝。已停止的容器清扫后照常激活；
  `--label` 多开与 `--dry-run` 语义不变。
- **`aisc maintenance cache-inspect`**（新子命令，只读）：镜像/容器/卷/构建
  缓存/网络逐项清单 + 去重后的可回收估算 + 「现有清理会命中」标记。绝不清理；
  现有 cache-cleanup 语义不变。Workbench 设置页「详细检测」基于它。

## 修复

- 无用户可见缺陷修复；本版核心即上述两项。

## 安装与更新

- pip：`pip install -U aisc-cli`（Debian 13 等受 PEP 668 管控的环境加
  `--break-system-packages`，或用 pipx）
- Workbench 内置 CLI 随下一版 NSIS 安装器更新
