# AISC Workbench v2.1.12-preview.1

> **Preview**（develop 分支预发布，prerelease——正式版需明确要求才发布）。
> 自更新载荷：Workbench NSIS 安装器（Windows x64），**自带本构建时最新 CLI**（装 UI 顺带装 CLI）。

## 本包亮点（相对旧安装）

- **Provider 模板化**：Codesome V3 / 二合一双模板（默认选中置顶）、获取服务直达、行 ID 多实例、key 前缀醒目校验
- **每模型思考等级**：模型映射行内多选下拉（八级）+ 默认深度，Codex `/model` 直接生效
- **自动压缩阈值**：按 provider 可配（默认预填），上下文到值自动压缩
- **编辑/删除健壮化**：单 provider 可编辑可删，不再误写其他行
- **镜像**：cc-switch 预置口（CN 网络韧性）+ 全局去预置（provider 完全由用户添加）

## 安装 / 更新

- 全新安装：双击 setup 即可（自动引导 Docker/Python/WebView2 依赖）
- 覆盖更新：直接安装，配置与工作区完整保留

## CLI 更新通道

- Workbench 用户：随本安装器自动更新（或 `aisc update` 工具/镜像部分）
- pip 用户：`pip install -U aisc-cli`（PyPI 与本 release 独立发版）
