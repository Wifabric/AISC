# 主题助手与记忆

在主题页选择「助手与记忆」，管理协作方式、记忆和方法基线。目标、限制和反馈仍可在普通 Claude/Codex 对话中提出，无需每次填写表单。

## 开始使用

1. 打开工作区，从标签栏菜单进入「主题实践工坊」，新建一个主题或选中已有主题。
2. 进入「助手与记忆」。新主题默认启用；旧主题需勾选启用并保存，原 `.skill/` 和历史记录保留。
3. 选择合作方式并保存：「一起做」共同推进并解释关键选择；「带我学」示范、试做和反馈；「直接做」优先完成可检查的成果。
4. 将主题设为新对话主题，打开新的 Claude/Codex 会话，直接提出任务。当前已打开的会话需要明确让助手重新读取设置。

新主题使用 topic-workshop 0.4.2。旧主题启用助手会添加平台维护的助手工具，不会覆盖之前固定的技能。

## 记忆的范围与维护

主题记忆分为偏好、条件与限制、实践经验、协作约定，可添加、修改、删除或停用。未经实践的经验保留为「待验证」；确认经验时填写依据和适用条件，不能把猜测写成结论。

工作区共享偏好需要显式启用，仅影响该工作区内启用助手的主题，不会自动传播到其他工作区。界面和对话助手写入同一份状态；遇到「内容已变化」错误，先刷新再修改，避免覆盖其他会话的更新。

记忆不是执行授权。删除记忆只停止后续使用，不会删除原始对话、修订记录或已有会话背景。本功能不在后台扫描所有历史来自动推断偏好。

## 使用扩展市场技能作为基线

1. 先在扩展市场安装所需 skill。
2. 回到「助手与记忆」，刷新已安装技能，选择技能并填写它在本主题中的用途。
3. 点击「固定为主题基线」。平台复制完整技能包（含引用资源），保存内容指纹，后续源技能更新或删除不会改变该副本。
4. 可以为不同用途固定多个基线。停止使用保留历史副本；采用新版时，先停止使用原基线，再从已安装技能重新选择。

基线是方法参考，不能覆盖用户目标、授权与平台约束。没有基线也可以正常使用助手。链接路径、非普通文件和超限技能包会被拒绝；单包最多 500 个文件、20 MiB，单文件最多 5 MiB。

## 反馈、迭代与记录

按「做出成果 → 检查 → 反馈预期与实际差异 → 最小修订 → 再验证」推进。首份可复用做法可以先写入主题手册，但需标明待验证、适用条件和产物入口；不能把草稿当成已经验证的经验。

主题目录的原始事件、修订快照、成果与 `ITERATION_LOG.md` 保留过程依据。普通聊天不自动算作一次方法修订。以后改进通用技能时，先从这些记录整理问题、假设、适用范围和验证结果；没有自动升级所有主题技能的后台任务。真实主题和完整案例属于用户本地资料，不随功能源码提交。

## 验证步骤

- 保存一种合作方式和主题偏好，刷新后确认仍存在；切换主题检查隔离。显式启用共享偏好后检查其工作区范围。
- 在两个读取了同一版本的窗口先后保存，后一次过期保存应拒绝覆盖；刷新后可重试。
- 固定一个含引用文件的已安装技能，修改来源后核对副本保持原内容；停止使用后新会话不再加载它。
- 在独立主题完成一次小任务并反馈一次，检查成果、手册的待验证标识、修订日志和下一步验证；不要用模拟检查替代真实使用效果。
- 对旧主题启用助手，核对原 `.skill/` 与历史文件未被替换。

## 构建注意

桌面安装产物使用项目的 Tauri 构建流程。直接使用 Cargo 构建时须启用 `--features tauri/custom-protocol`，否则会加载开发服务器地址而非内嵌界面。进程存在不等于界面加载成功，需核对前端启动的 CLI 握手，并补真实 UI 验收。
